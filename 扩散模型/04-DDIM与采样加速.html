04 · DDIM 与采样加速

⏱ 42 分钟 ｜ 阅读与实验参考，可分次完成 ｜ 先分清步数、随机性和复现条件

🎯 一句话

DDIM 用当前预测和目标噪声水平构造更新，允许选一张更稀疏的采样时间表。 它可以减少模型调用，但不是“去掉随机数就能无损跳步”，也没有所有模型通用的 50 步答案。

先把界面上的三个设置分开：

  • 步数：准备做多少次采样更新。更完整的成本还要数实际网络评估次数。
  • 采样器与调度表：每次怎样更新、选哪些噪声水平。
  • 种子：控制随机数的起点；它不是整套复现参数。

想理解跳步，先看两次计算；只想动手，去时间表或可复算的小实验。公式推导放在折叠里，不必先读完推导才继续。

上一章训练噪声预测器，本章用它生成样本。对于本页的噪声预测参数化，保持训练时的噪声表、时间标记和输入约定一致，可以复用权重来换采样方式；不能把任何预测类型的模型不加转换地代进来。

🐌 一、慢在哪：先数网络评估，再看单次成本

通常一次去噪的结果，是下一次去噪的输入；同一个样本的这条链需要依次执行。减少链上的更新次数，是加速的一条路。

但“步数”不一定等于“网络前向次数”。 某些求解器一次更新需要多次评估；CFG 还要取得有条件和无条件预测，可能合成一个更大的 batch 调用。比较速度时应同时记录这些设置。

一个便于理解的近似是：重复部分的耗时，取决于网络评估次数（NFE）与每次评估成本。最后还要加编码、解码、调度和数据搬运等开销。

同一批图片可以并行处理，这可能提高吞吐量，却不代表一次出 8 张几乎免费。计算量、显存和实际延迟都会受 batch 大小与硬件影响。

你可以从两端节省工作：本章减少或改善采样更新；下一章让反复去噪处理较小的潜变量。图的大小同样会影响单次成本，不能排除在外。

🎲 二、相邻步公式不能只改一个下标

不能直接把相邻步公式里的 t−1 改成 t−20，同时保留原来的系数。 原因是系数描述了特定的时间间隔，不是随机性禁止跳步。

本页用 $\beta_t$ 表示从 t−1 到 t 的加噪量，$\alpha_t=1-\beta_t$，$\bar\alpha_t=\prod_{s=1}^t\alpha_s$。横线表示从起点累计的信号保留比例，不是另一个可随意调的参数。

先看一步由什么组成：当前样本 $x_t$、模型预测的噪声，以及可能新抽取的高斯噪声 $z$。

查看相邻步 DDPM 公式与每一项

把均值单独记作 $\mu_t$，长式就可以分成两行：

$$\mu_t=\frac{1}{\sqrt{\alpha_t}}\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right).$$

$$x_{t-1}=\mu_t+\sigma_t z,\qquad z\sim\mathcal N(0,I).$$

  • $\epsilon_\theta(x_t,t)$ 是网络的预测，不是已知的真实噪声。
  • $\mu_t$ 是按这一步的系数算出的均值。
  • $\sigma_t z$ 提供新随机量；$\sigma_t$ 是标准差，方差是它的平方。

最后一步可以采用不再注入新噪声的约定。DDPM 也有不同方差选择，所以比较“等价”时必须说明采用哪一种。

若把时间表重新选得稀疏，并为新的间隔重算系数，随机采样仍然可以跳步。例如 OpenAI 的 respacing 实现会保留选中时刻的累计噪声比例、构造新的间隔参数，并映射回模型原来的时间标记。

因此，“按原相邻链完整执行要走完它的步数”是对指定算法的描述；“所有带随机项的算法都必须走 1000 步”则不是。

⏩ 三、DDIM 的一步：先估计，再走向选定的噪声水平

想象你正在 t=1000，准备直接到 t′=500。你需要当前的预测，也需要目标时刻的累计系数；不是简单把原来一个小步执行一半。

本页约定 $t'<t$，数学时间 0 是干净端点，$\bar\alpha_0=1$。为减少重复文字，把当前噪声预测简记为：

$$e_t=\epsilon_\theta(x_t,t).$$

第一个动作：估计干净样本

$$\hat x_0=\frac{x_t-\sqrt{1-\bar\alpha_t}\,e_t}{\sqrt{\bar\alpha_t}}.$$

先减去预测的噪声部分，再除以信号系数。帽子提醒你：这是估计，不是已经拿到了原图。高噪声时分母可能很小，预测误差也会被放大。

第二个动作：组合出目标时刻的样本

先给“沿当前预测方向的系数”起一个短名字，避免把三个根号挤在一行：

$$c=\sqrt{1-\bar\alpha_{t'}-\sigma^2}.$$

$$x_{t'}=\sqrt{\bar\alpha_{t'}}\,\hat x_0+c\,e_t+\sigma z.$$

从左到右读三个部分：

  1. 估计的干净样本，按目标信号比例缩放。
  2. 当前预测方向，按剩余噪声幅度缩放。
  3. 新的随机量，其大小由这段更新的 $\sigma$ 决定。

其中 z 是新抽的标准高斯，不能与前面的网络预测 $e_t$ 混为一谈。$\sigma=0$ 时第三项消失，前两项仍然要计算。

式子允许选择非相邻的 t′，但要求系数合法，例如 $0\leq\sigma^2\leq1-\bar\alpha_{t'}$。能计算一个大步，不等于这个大步与许多个小步有相同的生成质量。

为什么通常可以复用训练好的噪声预测器

噪声预测训练可以直接抽一个 t，从干净样本构造 $x_t$，再让网络预测噪声。它使用的是这个时刻的条件边缘分布 $q(x_t\mid x_0)$，不必在训练时模拟整条反向采样链。

DDIM 的构造保留这些边缘分布，改变时刻间的连接方式，从而复用常见的噪声预测训练。这里说的是兼容的预测目标与参数约定，不是所有变分目标的权重都严格相同。原论文 §3–4给出了构造及其代理目标的关系。

选读：保留边缘分布的那族条件分布

先固定每个时刻的边缘：

$$q(x_t\mid x_0)=\mathcal N\!\left(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I\right).$$

把给定真实 x₀ 时的标准化残差记作 r，把目标均值记作 m：

$$r=\frac{x_t-\sqrt{\bar\alpha_t}x_0}{\sqrt{1-\bar\alpha_t}}.$$

$$m=\sqrt{\bar\alpha_{t'}}x_0+\sqrt{1-\bar\alpha_{t'}-\sigma^2}\,r.$$

$$q_\sigma(x_{t'}\mid x_t,x_0)=\mathcal N(m,\sigma^2I).$$

给定 x₀ 且 t>0 时，r 的协方差为 I。新增高斯噪声独立于 r，因此两部分噪声的协方差相加为 $(1-\bar\alpha_{t'})I$，与所需边缘匹配；σ=0 时按退化的确定性条件分布理解。

这是知道真实 x₀ 时的构造。实际生成不知道 x₀，所以前面的更新换入预测的 $\hat x_0$；不能把这个替换之后的有限步生成分布直接宣称为精确的数据分布。

可以先停：你已经知道“一步怎样算”和“为什么可以选更少的时刻”。下一节只是在这个更新里调节新噪声的大小。

🎛️ 四、η：控制新噪声，不负责保证质量

常见的选择把这一段的标准差写成：

$$\sigma_{t\to t'}=\eta\sqrt{\frac{1-\bar\alpha_{t'}}{1-\bar\alpha_t}}\sqrt{1-\frac{\bar\alpha_t}{\bar\alpha_{t'}}}.$$

η 读作 eta。它是无量纲的控制系数；另外两项依赖这次更新的起点与目标，不能省略后直接把 η 当噪声标准差。

取值这一步发生什么
η = 0不再引入步内随机量。固定初始噪声、条件与全部计算约定后，数学更新是确定的。
0 < η < 1引入一定新噪声；质量和多样性的变化需要对当前模型实测。
η = 1在完整相邻网格、相同预测与后验方差约定下，对应 DDPM 更新；稀疏网格则是另一条链。

常用范围 0≤η≤1 能使本页系数合法。一般的 σ 仍须满足上一节的方差约束，不能任意调到根号内为负。

例如本页线性噪声表的 1000→500 大步，η=1 时，新增噪声方差约 0.920977，方向系数的平方约 0.000436，两者都合法。这是“随机且能跳步”的具体反例，不是这个大步画质好的证据。

采用其他 DDPM 方差、预测裁剪或额外引导后，“η=1 与某个实现完全等价”还需重新核对。DDIM 官方更新代码可以逐项对照这些系数。

少步数可能影响质量，但不能解释成“新增噪声必然要用后面几百步洗掉”。随机程度与时间网格都是设计选择，没有“少步数与随机性绝对不能兼得”的定律。

🔢 五、动手：从 1000 个噪声水平中选出 50 个

这段程序只打印时间表，不生成图片，也不是完整采样器。 需要 PyTorch，不下载模型，不需要 GPU。

这里保留 0、20、40…980 的数组索引例子。注意它采用零起始下标：代码 abar[0] 已经加过第一步噪声，对应前面数学记号的 $\bar\alpha_1$，不是干净端点 $\bar\alpha_0=1$。

# 从 1000 个已加噪的时间水平中选 50 个；本段仅查看表，不执行采样。
import torch

T = 1000
betas = torch.linspace(1e-4, 0.02, T)
abar = torch.cumprod(1.0 - betas, dim=0)   # 数组索引 t 对应数学时间 t+1

S = 50
tau = torch.arange(0, T, T // S)           # 本例 T 能被 S 整除
print(f"原始 {T} 步 -> 抽成 {len(tau)} 步，步距 {T // S}")
print("前 6 个时间步：", tau[:6].tolist())
print("后 6 个时间步：", tau[-6:].tolist())
print("\n    t     alpha_bar    信号系数     噪声系数")
for t in tau[::7].tolist():
    a = abar[t]
    print(f"{t:5d}   {a.item():10.6f}   {a.sqrt().item():8.4f}   {(1 - a).sqrt().item():8.4f}")

它选到 50 个点：前六个为 0、20、40、60、80、100，后六个为 880、900、920、940、960、980。打印是升序；实际生成通常反向走，并另行处理干净端点。

本例最后一个点是 980，不是 999。也不要把 T // S 当作适用于任意输入的选点器：不能整除时点数可能不是 S，S>T 时步距甚至会为 0。下一节的完整实验另外定义了含两端点的时间表。

要比较选点方式，应固定模型和评估任务，实际测生成质量与成本。仅看加噪系数不能替代这项实验。

🎰 六、固定轨迹有什么用：复现、图生图与插值

1. 复现：种子之外还要保存什么

η=0 时没有新的步内抽样，但初始噪声仍然是随机的。固定全部输入与计算之后，采样器定义一条确定轨迹。

分享结果时，同时记录模型及版本、提示词和负面提示词、尺寸、初始噪声或种子、采样器、步数、时间表、η、CFG 和其他处理设置。

硬件、精度、软件实现、batch 和浮点运算顺序也可能影响逐位复现。种子相同不意味着任意环境、任意设置都输出同一张图。

随机采样器也能复现，只要其所有随机流和计算条件得到控制。确定性 DDIM 减少了需要管理的步内随机量，不是让“复现”第一次成为可能。

2. 图生图：从选定噪声强度开始

先把参考图加噪到某个中间水平，再从那里去噪；潜空间模型还需要先编码参考图。strength 通常控制起始噪声水平或采样区间，但不同界面映射可能不同。

较小的加噪一般保留更多输入信息，较大的加噪允许更大变化。这是倾向，不是“必然只改细节”或“必然保留大结构”的保证。

比较 strength 时还要控制编码取样、前向加噪、初始随机数、提示词等条件。即使 η=0，若每次加噪用不同随机数，也不能把所有变化归因于这个滑块。

3. 插值：线性中点改变了噪声的尺度

令 A、B 是两个独立的 d 维标准高斯噪声，线性中点为 $(A+B)/2$。它的每维方差是 1/2，不是 1。

在本页 SD 1.x 尺寸例子中，d=4×64×64=16384。原噪声范数的理论均方根为 128，中点为约 90.51，比例为 $1/\sqrt2\approx0.7071$。这是均方根，不是某一次抽样的精确长度。

高维高斯的大部分概率质量集中在典型半径附近，但中心不是“空的”或概率密度为零。中点分布发生变化，不能进一步直接断言模型从未见过它、图一定发灰。

球面插值（SLERP）是控制方向和半径的一种选择。 归一化线性插值也能控制范数；它们都不自动保证完整高斯分布或生成图的语义连续。零向量、近同向与反向端点还需单独处理。

本页只核验噪声统计，没有运行图像插值质量实验。因此可以得出“线性中点收缩了尺度”，不能报告“使用 SLERP 后灰图问题已消失”。

📉 七、怎样判断增加步数有没有用

固定条件比较质量与成本，不预先规定 50 步够用。 下面采用很小的一维分布，能在 CPU 上复算，不需要训练网络。

先明确这次实验在测什么

目标分布有两个峰：一半样本来自均值 −2、标准差 0.5 的高斯，另一半来自均值 2、标准差 0.5 的高斯。

  • 每组 20,000 个样本，1000 个线性 β 从 0.0001 到 0.02。
  • 数学时间 0 是干净端点，abar[0]=1。每种 S 用 rint(linspace(1000, 0, S+1)) 选点，包含两端并执行 S 次更新；本页所列 S 都无重复点。
  • η=0；比较不同 S 时，复用同一初始噪声和同一真实参照样本 A。
  • 使用可解析计算的条件均值 $\mathbb E[\epsilon\mid x_t]$。它只看 xₜ 和 t，不知道当前样本隐藏的真实 x₀ 或 ε。

误差用一维 W1 距离。对于本页相等样本数的两组经验分布，将各自样本排序、逐位相减取绝对值，最后取平均即可；这是这个特殊情形的计算方法。Wasserstein 距离的定义可进一步对照。

它排除了神经网络训练误差，但仍有有限样本评估和有限终端噪声近似的影响，不是纯数值积分误差。

真实样本之间的距离，不是硬下限

同一次实验还独立抽了真实样本 B、C。得到 W1(A,B)=0.056764，而 W1(A,C)=0.027507。C 也是独立真实样本，却比 B 更接近 A。

因此不能把某一对真实样本的距离叫作“谁也低不过的地板”，也不能从生成误差中减去它，就把剩下的数命名为纯模型误差或纯离散误差。

不同种子会改变这些距离；例如种子 20260912 的 A/B 距离为 0.014690，A/C 为 0.041334，大小顺序反了。应报告抽样条件和多次结果，而不是挑一组有利数字。

运行完整小实验：只需 NumPy，复制到一个空文件即可

先看 sample：每轮估计 x₀，再按目标累计系数组合；epsilon_mean 提供本例的解析预测器。最后的三个真实样本来自独立随机流，没有重复用 A 与自己比较。

# New reproducible experiment; not a reproduction of the old table.
# CPU + NumPy only. W1 includes finite-sample and terminal-prior effects.
import numpy as np

T, N, SEED = 1000, 20000, 20260911
STEPS = (2, 5, 10, 20, 50, 100, 200)
betas = np.linspace(1e-4, 0.02, T, dtype=np.float64)
abar = np.r_[1.0, np.cumprod(1.0 - betas)]  # clean t=0: abar[0]=1

def draw_true(rng):
    means = np.where(rng.integers(0, 2, size=N), 2.0, -2.0)
    return means + 0.5 * rng.standard_normal(N)

def epsilon_mean(x, t):
    # Conditional mean E[epsilon | x_t], not a sample's hidden true noise.
    a = abar[t]
    v = a * 0.25 + 1.0 - a
    mean_component = 2.0 * np.tanh(np.sqrt(a) * 2.0 * x / v)
    return np.sqrt(1.0 - a) / v * (x - np.sqrt(a) * mean_component)

def sample(initial, steps):
    x = initial.copy()
    grid = np.rint(np.linspace(T, 0, steps + 1)).astype(int)
    for t, previous in zip(grid[:-1], grid[1:]):
        a, b = abar[t], abar[previous]
        eps = epsilon_mean(x, t)
        x0_hat = (x - np.sqrt(1.0 - a) * eps) / np.sqrt(a)
        x = np.sqrt(b) * x0_hat + np.sqrt(1.0 - b) * eps  # eta=0
    return x

def w1(x, y):
    return np.mean(np.abs(np.sort(x) - np.sort(y)))  # equal sample sizes

streams = np.random.SeedSequence(SEED).spawn(4)
rng_noise, rng_a, rng_b, rng_c = [np.random.default_rng(s) for s in streams]
initial = rng_noise.standard_normal(N)
true_a, true_b, true_c = [draw_true(r) for r in (rng_a, rng_b, rng_c)]
print("steps  W1(generated, true_A)")
for steps in STEPS:
    print(f"{steps:5d}  {w1(sample(initial, steps), true_a):.6f}")
print(f"W1(A,B)={w1(true_a, true_b):.6f}")
print(f"W1(A,C)={w1(true_a, true_c):.6f}")
print(f"W1(B,C)={w1(true_b, true_c):.6f}")

这里的 sample 只用于上面列出的有效 S；把任意步数或别的模型放进来，需要额外检查网格和接口。W1 公式也限本页等样本数的一维比较。

旧结果记录为何不再作为饱和结论的依据

此前本页列过 S=2、5、10、20、50、100、200，对应 W1 为 1.1473、0.2759、0.1326、0.0682、0.0298、0.0225、0.0228，并把另一组真实样本距离 0.0199 叫作地板。

这些旧数字缺少足以还原的完整参数与脚本，本次没有声称复现它们。即使数字来自某次有效运行，100→200 的单次上升也不能独自证明饱和，更不能证明有网络误差时只会更早饱和。

上面的新实验补齐了分布、网格、随机流和完整代码。保留要研究的问题——步数怎样影响质量——同时撤去不成立的“硬地板”和通用阈值推断。

🗓️ 八、步数、时间表和求解器怎样一起选择

先定比较条件，再改一个设置。 时间表决定在哪里评估，求解器决定怎样利用预测更新；两者都可能影响少步数表现。

三种选点思路

均匀选点。 在某个时间参数上等间隔取点，简单且便于比较。要说明是哪一个参数，并检查取整、重复点和端点；不能只写一个 range 就认为任意 S 都正确。

二次选点。 点的位置按索引的平方排布，可以使较低 t 的一端更密；是位置呈平方关系，不是相邻步距本身按平方增长。DDIM 原论文对 CIFAR-10 用过这种选择，对其他数据用了线性选择，不能改写为二次在所有少步数任务上都更好。

Karras 式噪声网格。 直接在噪声尺度上用幂律控制点位。EDM 官方采样实现提供了具体构造。它是一种可选设计，不是所有框架默认、所有 10–20 步设置都必胜的规则。

求解器：不只是换一张时间表

确定性 DDIM 在适当重参数化后，与常微分方程（ODE）的一阶 Euler 离散有关；这个表述有 η=0 和变量约定，不能把所有带随机量的更新都说成普通 ODE 的 Euler 法。

DPM-Solver、DPM-Solver++ 和 UniPC 等方法使用更高阶或多步的信息来改善有限评估预算下的近似。兼容模型的预测参数化后，通常不必为了更换这些求解器重训权重。

但某方法“十几步等于另一方法五十步”需要指定模型、引导、任务和质量指标。比较时同时记录实际 NFE；不能仅凭界面上的 step 数判断成本或精度。

可以先测试 20、50、100 等预算，再用多组固定种子与同一任务比较质量、耗时和显存。这是实验起点，不是合格步数清单。 若后两档仍有值得付费的改善，就继续测，而不是被“50 步足够”拦住。

✅ 检查点

  1. 为什么不能只把相邻步公式的 t−1 改成 t−20？这是否意味着随机采样绝对不能跳步？
  2. DDIM 为什么能复用常见噪声预测权重？需要保持哪些模型和时间约定？
  3. 一次更新怎样从噪声预测得到干净样本估计，再组合到目标时刻？估计为什么不是真实原图？
  4. η=0 去掉哪部分随机性？η=1 在什么条件下对应 DDPM，为什么不能不看网格就说完全等价？
  5. 时间表例子从索引 980 到 560 的信号系数怎样变化？这张表为什么不能证明均匀选点浪费或所有细节只在后半程形成？
  6. 新实验的 50、100、200 步结果说明什么？真实对真实的 W1 为什么不能作为硬地板或直接减掉的误差分量？
  7. 独立高斯噪声线性中点的方差和典型半径怎样变化？为什么 SLERP 只是一个选择，不能自动保证生成画质？
👀 答案
  1. 相邻步系数对应指定间隔，换目标必须重新构造系数。合法的稀疏随机更新存在，随机项不是禁止跳步的原因。
  2. 构造保留训练使用的条件边缘分布，能复用兼容的噪声预测训练。实际还要对齐噪声表、时间标记、输入尺度、预测类型及必要转换；不能说任意变分损失权重都完全一样。
  3. 先从 xₜ 减去预测噪声、除以信号系数得到 x̂₀，再把目标信号、预测方向和可能的新随机量组合起来。网络只有当前观测，可能预测不准，尤其高噪声下误差会放大；换用估计后不再自动拥有真实条件分布的精确性。
  4. η=0 去掉新增步内噪声，不去掉随机初始噪声。η=1 在完整相邻网格、相同预测与后验方差等约定下对应 DDPM；稀疏网格、不同方差或其他处理会改变比较对象。
  5. 约从 0.0077 变成 0.2022。它描述加噪系数，不描述模型正在学或正在生成的全部结构；判断选点效率需要受控的质量与成本测量。代码索引 0 还不是数学上的干净端点。
  6. 单种子结果依次为 0.027475、0.014568、0.011184；100→200 仍改善，但不支持通用图像阈值。真实样本之间的经验距离会随抽样变化，另一组真实样本就可能更近；它既非下界，也不与生成误差构成可直接相减的分解。
  7. 中点协方差为 I/2，范数的理论均方根缩为原来的 1/√2；d=16384 时由 128 变成约 90.51。高斯中心不是空的。SLERP 或归一化线性插值可控制半径，但完整分布、端点边界和图像语义仍需检查，不能直接保证不发灰或更清楚。

⚡ 走神救援

先记住这几件事

  • 跳步要匹配新间隔的系数；随机采样也能采用稀疏网格。
  • DDIM 用预测的干净样本和目标噪声水平构造更新，预测不等于真实原图。
  • η=0 仍有随机初始噪声；复现需保存模型、条件、时间表和计算环境。
  • 步数是否值得增加要实测；真实样本间的一次距离不是误差地板。
