03带着目标，走一条路线

想边学边做？从一份具体成果开始。

从零基础↗

输入与预测 → 评估 → 环境与方向。七步留下训练/测试对照。

可先观察 · 动手另计

RAG 项目↗

入库与权限 → 解析 → 检索 → 引用与评测。七步交出报告和失败清单。

真实生成与人工语义复核分开

Agent 工程↗

工具合同 → 审批恢复 → 状态与隔离 → 重试预算。七步保存行为证据。

真实传输、公开回放各有范围

面试复习↗

短回答 → 原始证据 → 失败与限制。七步留下六张口述卡和答辩材料。

公开冻结题不称独立盲测

查看实验状态 ↗ · 代码可用、本地实跑、合成回放与人工质量复核分别记录。
