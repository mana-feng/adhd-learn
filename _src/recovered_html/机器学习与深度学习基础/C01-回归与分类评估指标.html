C01 · 分类与回归的评估指标：分数究竟表示什么

⏱ 阅读约 21 分钟 · 动手实验另计

“准确率 95%”是不是意味着这个模型找到了 95% 的超时订单？

不一定。评估不是盯着某个漂亮数字，而是先明确你希望预测什么、错在哪一类代价更大。本章从真实标签和预测结果的对照表开始，逐项计算分类与回归指标。

完成后能手算 TP/FP/FN/TN、Accuracy、Precision、Recall、F1；能改变阈值观察取舍；会从残差计算 MAE、RMSE 和 R²，并区分训练损失与验证指标。

前置：A04 · 数据划分、03a · 二分类；B05 · 多分类 可作为补充。下一节：05 · 泛化、交叉验证与数据泄漏，继续学习“分数可信不可信”。

一、先看一个“95% 准确率”的陷阱

有 100 张历史订单，其中 5 张真正超时、95 张准时。若模型对每一单都回答“准时”，就能猜对 95 单：Accuracy=95/100=95%。但它连一张超时单都没有找到，超时召回率为 0/5=0%。

所以：预测是否正确和是否找到你真正关心的正例不是同一件事。本章假设“超时=1”为正类，“准时=0”为负类；如果任务改成识别准时订单，正负类定义也要改变。

二、混淆矩阵：先数四种结果

还是上面的 100 单，另一个模型预警了 10 单，其中 4 单确实超时，6 单其实准时；剩余没有预警的订单中，1 单超时、89 单准时。

真实结果 ↓ / 模型预测 →预测超时（1）预测准时（0）合计
真实超时（1）TP=4 真正例FN=1 假负例5
真实准时（0）FP=6 假正例TN=89 真负例95
合计1090100

TP（true positive）是找对的超时单，FP（false positive）是误报，FN（false negative）是漏报，TN（true negative）是识别正确的准时单。先数四格，再计算指标，避免混淆分母。

指标定义（分母为什么这样选）代入本例
Accuracy 准确率所有订单中预测正确的比例：(TP+TN)/全部(4+89)/100=0.93
Precision 精确率被模型预警的订单中真正超时的比例：TP/(TP+FP)4/(4+6)=0.40
Recall 召回率真正超时的订单中成功找到的比例：TP/(TP+FN)4/(4+1)=0.80
Specificity 特异度真正准时订单中识别正确的比例：TN/(TN+FP)89/(89+6)≈0.937
F1精确率与召回率的调和平均：2PR/(P+R)2×0.4×0.8/(0.4+0.8)≈0.533

这个模型准确率 93%，比“全部预测准时”的 95% 低，但找出了 4/5 的超时单。哪一个更合适取决于漏报和误报的实际代价；不能只按单一数字排名。

为什么 F1 不是 Precision 和 Recall 的普通平均？

普通平均 (0.4+0.8)/2=0.6，而 F1 是调和平均：2/(1/0.4+1/0.8)=0.533。调和平均更关注两者中较低的一项。假设某个模型 Precision=1、Recall=0.01，那么简单平均约 0.505，F1 仅约 0.0198，能提醒我们严重失衡。

阈值为 0.50，预测 5 单超时；找到了全部 3 单真正超时，但误报了 2 单。

尝试：将阈值改为 0.80，会出现 TP=2、FP=0、FN=1、TN=7：精确率提高到 100%，召回率降到 2/3≈66.7%。提高阈值不一定提高所有指标，也不是越低越好。

若预测正例为 0，则 Precision 的分母 TP+FP=0，数学上未定义；实验会显示“未定义”，而不是偷偷把它当作 100%。如果没有真实正例，Recall 同样无法按上述分母计算。

四、ROC-AUC 与 PR-AUC 是在测什么

前面的 Precision、Recall、F1 都取决于阈值。如果希望比较模型在多个阈值下的排序能力，就要看曲线。

ROC 曲线把每个阈值对应的 FPR=FP/(FP+TN) 放在横轴、TPR=TP/(TP+FN)=Recall 放在纵轴。ROC-AUC 是曲线下面积，也可解释为随机取一个正例与一个负例时，正例得分排在负例前面的概率（遇到相同分数按半个计）。它衡量排序，不保证概率校准，也不等于准确率。

PR 曲线使用 Recall 为横轴、Precision 为纵轴；当正例很少、误报成本突出时，通常值得结合 PR 曲线和正例基线一起看。注意不同库报告的 Average Precision (AP) 和“梯形插值 PR-AUC”计算方式可能不同，比较时要统一定义。

五、回归不能用“预测对几单”的准确率

预测配送分钟数时，目标是连续数值，分类的 TP/FP 不合适。我们用三张独立的演示订单：

订单实际 y（分钟）预测 ŷ（分钟）误差 ŷ−y（分钟）平方误差（分钟²）
甲1012+24
乙2018−24
丙3033+39

MAE（平均绝对误差）是绝对误差的平均：MAE=(2+2+3)/3=7/3≈2.333 分钟。它直接回答“平均偏差几分钟”。

MSE 是平方误差平均：MSE=(4+4+9)/3=17/3≈5.667 分钟²。为回到分钟单位取平方根：RMSE=√(17/3)≈2.380 分钟。RMSE 相比 MAE 更强调较大的误差。

R²（决定系数）与“始终预测样本均值”的基线比较。这里真实值均值 ȳ=(10+20+30)/3=20 分钟；基线平方误差为 (10−20)²+(20−20)²+(30−20)²=200。

R²=1−(4+4+9)/200=1−17/200=0.915。R² 是无单位的比例型指标，可能为负值；它不是概率，也不代表“91.5% 的样本预测正确”。当真实 y 全部相等时，常用 R² 定义的分母为 0，需要特殊处理。R² 的具体评估方式也依赖基线和数据集。

六、最小 Python 验算

from math import sqrt

tp, fp, fn, tn = 4, 6, 1, 89
precision = tp / (tp + fp)
recall = tp / (tp + fn)
f1 = 2 * precision * recall / (precision + recall)
accuracy = (tp + tn) / (tp + tn + fp + fn)
print(round(accuracy, 3), round(precision, 3),
      round(recall, 3), round(f1, 3))  # 0.93 0.4 0.8 0.533

y = [10, 20, 30]
pred = [12, 18, 33]
errors = [a - b for a, b in zip(pred, y)]
mae = sum(abs(e) for e in errors) / len(y)
rmse = sqrt(sum(e*e for e in errors) / len(y))
baseline = sum((v - sum(y)/len(y))**2 for v in y)
r2 = 1 - sum(e*e for e in errors)/baseline
print(round(mae, 3), round(rmse, 3), round(r2, 3))
# 2.333 2.38 0.915

指标应在验证集或最终测试集上报告，而不是拿训练集的漂亮分数充当真实泛化能力。如果要选择阈值和模型，应先在验证数据上完成选择，最后才查看测试集。

七、检查自己是否真的理解

  1. 若真实超时 5 单，模型只找出 4 单，漏掉 1 单，Recall 的分母应该是 5 还是 10？
  2. 为什么将阈值从 0.50 调到 0.80 后，Precision 可能升高而 Recall 下降？
  3. 为什么三个回归样本的 RMSE 单位是分钟，而 MSE 是分钟²？
展开答案

① 分母是实际正例数 TP+FN=5，故 Recall 为 4/5=0.8。② 更高阈值使模型只预警更有把握的订单，可能减少误报，也可能漏掉部分真正超时的单。③ MSE 对误差平方后平均，单位也被平方；RMSE 再开平方回到目标原单位。
