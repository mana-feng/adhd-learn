E02 · DBSCAN 与层次聚类：不必预先告诉模型有几类

⏱ 阅读约 21 分钟 · 实验另计

K-Means 要先定 K 个簇；如果数据里有两个稠密的小群和一个孤零零的点呢？

这篇用七个一维数据点，让你自己数邻居，识别 DBSCAN 的核心点、边界点和噪声；再换成层次聚类的视角，观察“群是怎样一步一步合并”的。

学完后能手算一个 DBSCAN 小例子、解释 eps 与 min_samples、画出单链接聚类的合并顺序，并说明三种聚类方法各自可能失效的地方。

前置：06 · K-Means 与 PCA。K-Means 先找质心，DBSCAN 找稠密邻域；同一份无标签数据没有可直接偷看的“标准答案”。下一节：将在 E05 学习异常检测的专门任务；概率聚类的进阶数学可选读 EM 与高斯混合。

一、先把问题和数据摆出来

这次不使用配送的真实标签——聚类时根本不知道每个点应属于哪一群。只取七条人为构造的一维数值记录，其坐标依次是 A=0, B=1, C=2, D=6, E=7, F=8, G=15，它们可以代表已经缩放到同一尺度的某项特征（因此此处没有物理单位）。

肉眼可能觉得 A/B/C 一组、D/E/F 一组，G 是孤立点，但这只是候选的结构。一个算法的结论要依赖它所选择的距离、邻域半径与密度标准。我们先统一使用一维绝对距离 d(xᵢ,xⱼ)=|xᵢ−xⱼ|。

eps=1.1、min_samples=3：B 与 E 是核心，A/C/D/F 是边界，G 是噪声，得到两簇。

先按默认设置观察两组与噪声，再尝试调节 eps 和 min_samples。图例用描边区分：核心点粗实线，边界点细实线，噪声点虚线；无需依赖颜色理解分类。

二、DBSCAN 的每个符号从哪里来

eps（ε） 是两个点被视为“邻近”的最大距离。对某个点 p，把和它距离不超过 ε 的点收集起来，记作ε 邻域：Nε(p)={q: d(p,q)≤ε}。这里 q 遍历所有样本；p 自身到自己的距离为 0，因此计数包含自己。

min_samples 是定义核心点的最少邻域样本数。若 |Nε(p)|≥min_samples，点 p 就是核心点（core）；若 p 不是核心，但落在至少一个核心点的邻域内，它是边界点（border）；剩下的点是噪声（noise）。符号 |Nε(p)| 表示集合中点的个数，不是绝对值运算。

默认设定 ε=1.1，min_samples=3。逐个数：

点ε 邻域（包括自己）数量分类
A(0)A、B2边界
B(1)A、B、C3核心
C(2)B、C2边界
D(6)D、E2边界
E(7)D、E、F3核心
F(8)E、F2边界
G(15)G1噪声

B 核心点可以把 A、C 纳入同一簇；E 核心点可以把 D、F 纳入另一簇。两边之间最近的是 C(2) 与 D(6)，差 4，超过 1.1，无法连通；G 到最近的 F 相差 7，因此仍是噪声。

核心点之间通过连续的 ε 邻域连接，会把簇扩展下去；边界点可以归入簇，但不会像核心点一样继续把其他点扩展开。当边界点同时邻近多个簇时，它可能被不同扫描顺序分配给不同簇；核心簇结构通常更稳定，本实验采用固定 A→G 的遍历顺序以保证结果可复现。

三、一次修改参数，为什么可能全部成为噪声

把 ε 改成 0.5，所有相邻点都至少相差 1；于是每个点只有自己一个邻居，若 min_samples=3，便没有核心点，七点全是噪声。这并非算法失败，而是你要求的“局部密度”过于严格。

保持 ε=1.1，把 min_samples 改成 2：A/C/D/F 也成为核心点；仍可形成 ABC、DEF 两簇。若把 min_samples 改成 4，默认这七个点没有核心，全部是噪声。

如果 ε 增大到 4.1，C 与 D 相距 4，可以通过核心点形成密度连通，原来的两群可能合并为一群，而 G 仍可能是噪声。请用滑块实际验证这些判断。

关键限制：一个全局 eps 不容易同时适应“非常密”和“非常稀”的不同簇；高维距离、特征缩放、重复点以及样本量都会影响合理参数。探索时可以查看 k-distance 图，但不应把某条视觉拐点当作唯一真值。

四、层次聚类：从每个点一组开始

DBSCAN 是找密度连通区域。凝聚式层次聚类（agglomerative clustering） 则从“每个样本各是一组”开始，每次挑当前距离最近的两组合并，直到达到指定簇数或距离阈值。

为了方便手算，换成另一组独立的小例子：A=0, B=1, C=5, D=6。先使用单链接（single linkage）：两组之间的距离，取两组样本两两距离中的最小值。

  1. 初始四组：{A}, {B}, {C}, {D}。
  2. A 与 B 相距 |0−1|=1；C 与 D 相距 |5−6|=1，都最小。因此前两次合并在距离 1 完成，得到 {A,B} 与 {C,D}（这两次顺序可互换）。
  3. 最后比较两组跨组的所有距离：|0−5|=5、|0−6|=6、|1−5|=4、|1−6|=5。单链接取最小，合并高度为 4。

如果改用全链接（complete linkage），最后两组的距离就取跨组最大距离 6；平均链接则取四个跨组距离的平均值 (5+6+4+5)/4=5。同一组数据换定义，就会得到不同合并高度，甚至不同的整体树结构。

五、K-Means、DBSCAN 与层次聚类要解决的差别

方法主要机制优势容易出问题的地方
K-Means分配给最近质心、反复更新均值速度通常较快、结果简单需先给 K，受初始值、离群点及簇形状影响
DBSCAN稠密核心连通，单独标记噪声不必先给簇数，能找非球形簇eps / 密度敏感，难处理密度差异很大的簇
凝聚层次聚类按链接准则逐步合并可看多层次分组关系距离和链接策略影响大，规模大时计算代价可能很高

无监督算法不直接提供“真实类别”，也不保证分成两群就是自然界里存在两类。应该结合原始特征、业务目标、稳定性和需要的下游任务判断是否有用。

六、运行代码，对照前面的手算

from sklearn.cluster import DBSCAN, AgglomerativeClustering

xs = [0, 1, 2, 6, 7, 8, 15]
X = [[float(x)] for x in xs]
labels = DBSCAN(eps=1.1, min_samples=3).fit_predict(X)
print(labels.tolist())  # [0, 0, 0, 1, 1, 1, -1]
# -1 代表噪声；0 和 1 是算法分配的簇编号，不是原本的真值

small = [[0.0], [1.0], [5.0], [6.0]]
h = AgglomerativeClustering(n_clusters=2, linkage="single")
groups = h.fit_predict(small)
print(groups[0] == groups[1], groups[2] == groups[3],
      groups[0] != groups[2])  # True True True
# 聚类编号可能换序，只验证 A/B 同组、C/D 同组且两组不同。

这里只对训练式探索调用聚类算法，并未展示“用训练簇分类新的订单”。标准 DBSCAN 的 sklearn 类没有像监督分类器那样的标准 predict 新样本接口；如果实际产品需要在线分组，还得另行设计簇分配规则和验证方案。

七、检查点：能复述整个推理过程吗

  1. 默认 eps=1.1、min_samples=3 时，为什么 A 是边界而 B 是核心？
  2. 把 eps 缩到 0.5，为什么没有核心点？
  3. 在小例子 A=0、B=1、C=5、D=6 中，为什么单链接最后合并距离是 4 而不是 6？
展开答案

① A 的邻居只有 A/B 两个，B 的邻居包括 A/B/C 三个，恰好达到 3。② 所有不同点之间至少相差 1，0.5 内只有每个点自己，邻域点数不达 3。③ 单链接在两组之间取最短的跨组样本距离，这里 B(1) 到 C(5) 距离 4；6 是全链接取最大距离的结果。
