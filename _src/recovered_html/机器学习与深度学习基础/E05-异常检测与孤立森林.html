E05 · 异常检测：LOF 与 Isolation Forest

⏱ 阅读约 22 分钟 · 实验另计

一个点非常接近整体均值，却可能远离每一群正常样本，这是为什么？

异常检测不是机械地删除极端值。它要找出偏离正常模式的样本。本章从一个能手算的近邻距离实验开始，再比较LOF 的局部密度和孤立森林的随机切分两条思路。

读完能分清数据清洗、离群点检测和新颖性检测；手算近邻异常分数，解释 LOF 与 Isolation Forest 的判断机制，并知道如何核验稀有异常。

前置：D01 · KNN、06 · 聚类与降维、E02 · DBSCAN。随后：可以继续 07 · 神经网络，或在 数据这一关了解异常值清洗。

一、先分清“异常”“错误”和“罕见”

数据清洗针对明显录入错误，例如配送距离被意外填成负数；但真实发生的大订单也可能很罕见，不应随意删除。离群点检测（outlier detection）在可能混入异常的训练数据中找不寻常的样本。新颖性检测（novelty detection）先从基本正常的训练样本学习模式，再检查未来未知的新记录。

本章交互模拟新颖性检测：候选新样本不能偷偷参与训练时的距离分布。异常分数高只代表“值得复核”，不是“必然错误”或“欺诈概率”。

二、全局均值可能恰好落在两个簇之间

下面八个人工构造的正常训练点来自一个已缩放的数值特征：[0.0,0.2,0.4,0.6,9.0,9.2,9.4,9.6]。左边一团在 0 附近，右边一团在 9 附近。

整体均值 μ=(0+0.2+0.4+0.6+9+9.2+9.4+9.6)/8=38.4/8=4.8。新点 x=5.0 与均值只相差 |5.0−4.8|=0.2；如果只看“距均值多远”，它显得十分普通。然而训练集中并没有任何点在 5 附近。

这提示我们：如果数据本来就有多个密集区域，单一均值可能掩盖两团之间的稀疏空白。

三、先手算一个简单异常分数

借用 KNN 的思路。定义教学用近邻距离分数：

s₂(x)=[d(x,n₁)+d(x,n₂)]/2

x 是待检测的新样本；n₁、n₂ 是正常训练集中距离 x 最近的两个点；d(x,a)=|x−a| 是绝对距离；s₂ 是两个距离的算术平均。它越大，表示新点距离已知正常点越远。这不是正式的 LOF 公式，只是一个可手算的起点。

  1. 对于 x=5.0，到右群的 9.0 是 |5−9|=4.0，到 9.2 是 |5−9.2|=4.2；到左群最近的 0.6 是 4.4，还更远。
  2. 因此最近两点为 9.0 和 9.2，分数 s₂(5.0)=(4.0+4.2)/2=4.1。
  3. 如果新点在 x=0.3，最近两点是 0.2 和 0.4，距离各 0.1，故 s₂(0.3)=0.1。对于 x=9.3，最近两点是 9.2 和 9.4，也得到约 0.1。

比较：5.0 离全局均值仅 0.2，却离最近两个正常样本平均达 4.1；0.3 和 9.3 的近邻分数都约 0.1。异常是相对于正常数据的结构而言的。

五、LOF：比较自己和邻居的密度

刚才的距离平均值无法自动适应密度不同的区域。LOF（Local Outlier Factor）多问一步：邻居们彼此很密集，而我离邻居很远吗？这时我可能是局部异常；如果整个区域原本就很稀疏，不能用同一个绝对距离标准生搬硬套。

先定义 Nₖ(p) 为点 p 的 k 近邻集合；k-distance(o) 为邻居 o 的第 k 近邻距离。实际遇到并列距离可能产生超过 k 个邻居。使用可达距离避免极近邻产生不稳定比值：

reach_distₖ(p,o)=max[k-distance(o),d(p,o)]

lrdₖ(p)=1/mean(所有 o∈Nₖ(p) 的 reach_distₖ(p,o))

LOFₖ(p)=mean(所有 o∈Nₖ(p) 的 lrdₖ(o))/lrdₖ(p)

这里 max 取两数中较大者，d 是距离，lrd 是“局部可达密度”，即平均可达距离的倒数。最终 LOF 将邻居的平均密度除以自己的密度。值接近 1 表示密度相近，明显大于 1 表示自己比邻居稀疏，但没有普遍正确的固定阈值。

做一个独立的假设性代入（并非前面八点的真实 LOF 计算）：某点的局部密度 lrd(p)=0.2，两个邻居密度分别 1.0 和 1.2，那么 LOF=[(1.0+1.2)/2]/0.2=1.1/0.2=5.5，说明该点比邻居稀疏得多。对数值和符号不熟悉时先抓住“比较相对密度”，无需一开始背所有公式。

六、Isolation Forest：谁更容易被随机切分隔开

孤立森林（Isolation Forest）走另一条路。它随机选特征和切分阈值，反复分裂数据。一个点若很容易单独被分出来，所需切分次数（路径长度）通常比较短；孤立森林会综合许多棵随机树的路径长度评估异常程度。

比如一维数据 [1.0,1.2,1.4,1.6,8.0]，只要第一刀的随机阈值落在 1.6 与 8.0 之间，8.0 就能被独立隔开；其他 1.0～1.6 的点通常还需继续划分。一次切分并不能证明异常，真实算法还要综合多棵树，并考虑样本量和随机性。

与 LOF 不同，孤立森林不依赖先计算每个点的近邻密度。但它同样会受到特征选择、数据分布和阈值设置影响，不能保证每个群间空白点都会被识别出来。

七、代码：正常训练集与新查询集分开

仍然使用八个训练正常点，接着分别检查 0.3、5.0 和 9.3。注意 novelty=True 表示 LOF 的新颖性检测模式，允许预测未参加训练的新样本；不应把此处的接口混成“检测同一批训练点本身”。

from sklearn.neighbors import LocalOutlierFactor
from sklearn.ensemble import IsolationForest

normal = [[x] for x in [0, .2, .4, .6, 9, 9.2, 9.4, 9.6]]
new = [[.3], [5.0], [9.3]]

lof = LocalOutlierFactor(n_neighbors=2, novelty=True, contamination=.1)
lof.fit(normal)
print("LOF:", lof.predict(new).tolist())
print("LOF scores:", lof.decision_function(new).round(3).tolist())

forest = IsolationForest(n_estimators=100, random_state=42, contamination=.1)
forest.fit(normal)
print("Isolation Forest:", forest.predict(new).tolist())
print("IF scores:", forest.decision_function(new).round(3).tolist())

# sklearn 的 predict 通常采用 1=正常、-1=异常；
# decision_function 越小越异常，低于 0 表示超过模型阈值。
# 两种算法不保证一致：输出需要结合真实标签或人工复核解释。

参数 contamination=.1 影响阈值选择，不是“每单都有 10% 的异常概率”；八条数据很小，无法证明真实业务性能。正式项目还应遵守 C05 的训练集预处理规范。

八、怎样评估一个异常检测系统

若有经过核实的异常标签，用 C01 的 Precision、Recall、PR 曲线衡量实际漏检与误报，特别关注专家复核成本。若没有标签，可使用人工审查、已知问题注入和时间回测积累证据，但不能把它们说成已得到客观的真实准确率。

  1. 为何新点 5.0 离均值 4.8 很近，却仍值得检查？
  2. LOF 和孤立森林各主要依赖什么信息？
  3. 如果只拥有比较干净的正常训练数据，优先考虑新颖性检测还是训练集离群点检测？
展开答案

① 正常数据分在两端，5.0 到最近两个正常点的平均距离为 4.1。② LOF 对比局部密度，孤立森林分析随机划分的平均路径长度。③ 新颖性检测：先用正常数据学习，再评估未来样本；仍须验证数据与部署时的分布是否一致。
