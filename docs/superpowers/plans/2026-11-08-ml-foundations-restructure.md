## 二、写作标准（所有新写或重写的页都按此验收）

1. **顺序**：现象 → 概念 → 公式 → 代码 → 数学推导。公式出现前，读者已经手算过一次。
2. **每个新概念七件套**：它是什么 · 为什么需要 · 解决什么问题 · 怎么工作 · 一个能自己算的例子 · 一个能自己动手的小练习 · 和前面哪一章接上。
3. **一套数据贯穿**：入门段（02a → 03 → 03a → 03b）全部用同一组房子；换数据必须明说「为什么换」。
4. **检查点分两层**：先「能算出来」（给公式和数，算预测 / 误差 / 下一步），再「能说出来」。
5. **术语先用白话、后给名字**；不能用后文才讲的词（梯度、验证集、学习率……）而不先给一句可操作的解释。
6. 保留专业深度：严谨限定收进「🔎 细节」折叠或标「进阶 · 可跳过」的页，不删除。

## 四、02a · 手动训练一个模型（新页大纲）

数据：3 套房子 `(50㎡, 120 万) (80㎡, 180 万) (100㎡, 220 万)`，真实规则 `价格 = 2 × 面积 + 20`（带偏置，顺带讲 b 为什么存在）。

1. **猜一个规则**：`价格 = 1 × 面积`，列表算出 3 个预测，全部偏低。
2. **算错了多少**：逐套算残差，再合成一个数（先绝对值、再平方 → 引出「算错误的规则 = 损失函数」，MAE / MSE 只给名字）。
3. **手动调**：w 改成 2，误差变小但仍差 20 → 发现「光乘不够，还要加一个起点」→ 偏置 b。
4. **挪一点看变化**：w 从 2 挪到 2.1，损失增加多少；挪到 1.9 呢？→ 「往哪边挪损失变小、变得多快」就是梯度（摸底中验证有效的讲法）。
5. **让机器自己挪**：每次沿让损失变小的方向挪一小步 → 梯度下降；步子太大（来回跳）/ 太小（半天不动）各算一次 → 学习率。
6. **十几行代码**：numpy 实现上面的循环，打印每轮 w、b、损失，看它自己走到 2 和 20。
7. **检查点（计算题）**：给 w、b 算预测；给预测和真实算误差；给两次挪动的损失变化判断该往哪边调。

图（按 02 / 03 的配色与验收规范）：误差竖线图、损失随 w 变化的碗形曲线（标出「挪一点」的两个点）、梯度下降每一步落点、学习率过大 / 过小对比。
