| 节 / 图 | 知识点 | 来源与原文要点 | 页面写法 |
|---|---|---|---|
| 一 | 分类：标签只取 0 / 1 两个值；1 为正类 | CS229 第 2 章开头：二分类里 y 只取 0 和 1，1 叫 positive class | 一致；「超时」记 1 |
| 一 · `ml03a-reg-vs-cls` | 回归预测连续值，分类预测离散类别 | CS229 第 2 章开头：分类和回归一样，只是要预测的 y 只取少数几个离散值 | 一致；左卡的「31 分钟」用 03 的规则 3 × 4 + 4 × 0 + 1.5 × 6 + 10 算 Q 单（设不下雨），脚本断言 |
| 一 · `ml03a-reg-vs-cls` | 为什么不先预测分钟数：数据可能只有类别标签；需要的是概率 | 课程自编的教学动机，不是来源中的结论；MLCC-SIG 只说明逻辑回归输出概率 | 两张理由卡是场景说明 |
| 二 | 分数 z = 加权求和 + 偏置，再过 Sigmoid 得到 0～1 的概率 | MLCC-SIG：z 是线性式 b + w₁x₁ + … 的输出，再送进 sigmoid；输出总在 0 和 1 之间。CS229：h(x) = g(θᵀx)，g(z) = 1/(1+e^{−z}) | 一致 |
| 二 · `ml03a-sigmoid-points` | 曲线形状：z → +∞ 趋于 1，z → −∞ 趋于 0，σ(0) = 0.5 | CS229 2.1 节 g(z) 的图与说明 | 一致；三点的数值由 `svgs.check_numbers()` 复算 |
| 二 | z 又叫 log-odds | MLCC-SIG：z 也叫 log odds | 页面未展开这个名词，只在本表记录 |
| 三 | 概率超过阈值才判为正类；0.5 不总是最好，按两类错误的代价选阈值 | MLCC-THR：概率高于阈值的样本判为正类；某一类错误代价更高时，用 0.5 并不好 | 一致；「漏报 / 误报」是 05 的假负 / 假正的白话说法 |
| 三 · `ml03a-threshold-line` | 阈值降低 → 判为正类的变多，误报增加、漏报减少 | MLCC-THR 习题答案：提高阈值，真正例与假正例都减少，真负例与假负例都增加（反过来即降低阈值的效果） | 一致；图里两条概率轴分别画阈值 0.5 和 0.3，R 从「漏报」变成「抓住」 |
| 四 · `ml03a-loss-push` | 交叉熵（log loss）公式；log 是自然对数；每单的梯度 p̂ − y | MLCC-LOSS 给出 Log Loss = −(1/N)Σ[y log y′ + (1−y) log(1−y′)]。SK-LL：单样本 −(y log p + (1−y) log(1−p))，「The logarithm used is the natural logarithm (base-e)」 | 一致；三单的 0.09、0.11、1.04 与平均 0.41 已复算 |
| 四 | 逻辑回归不用平方损失 | MLCC-LOSS：sigmoid 输出变化率不恒定，平方损失不适合 | 页面沿用原 03 的图 `ml03-ce-vs-mse`，图注已写明「并非绝对不能用 MSE」 |
| 四 / 🔎 | 交叉熵对 z 的导数 = p̂ − y | CS229 式 (2.5)–(2.6)：∂ℓ_logistic/∂t = 1/(1+exp(−t)) − y | 一致；R 单用「挪 0.01」数值验证 −0.645 ≈ −0.646 |
