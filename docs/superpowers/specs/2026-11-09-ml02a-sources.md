## 知识点 → 来源

| 节 / 图 | 知识点 | 来源与原文要点 | 结论 |
|---|---|---|---|
| 一句话、走神救援 | 训练四步：算损失 → 定方向 → 挪一小步 → 重复 | MLCC-GD 原文列出这四步 | 一致 |
| 一 · `ml02a-first-guess` | 特征 = 输入信息，标签 = 要预测的答案 | D2L-LR：要预测的叫 label（target），预测依据的变量叫 features | 一致 |
| 一 | 残差 = 实际 − 猜的 | NIST：残差 = 观测值 − 预测值，eᵢ = yᵢ − f(xᵢ) | 一致。2026-11-09 按用户选择的方案 B 改正（原来写成「猜的 − 实际」，正负号相反），和 04a、04b 一致 |
| 二 · `ml02a-loss-combine` | 损失 = 把错误合成一个数，越小越好；损失只看距离，不看方向 | MLCC-LOSS：损失是衡量预测错多少的数值指标，关注距离而不是方向 | 一致 |
| 二 | MAE = 绝对值平均，MSE = 平方再平均 | MLCC-LOSS：MAE 是 L1 损失的平均，MSE 是 L2 损失的平均 | 一致 |
| 二 | 平方会放大大错误，模型会优先改正离谱的单 | MLCC-LOSS：平方让大的差距变得更大，MSE 会让模型更偏向离群点，MAE 不会 | 一致 |
| 二 | 平方是光滑曲线，便于「挪一点」计算 | D2L-LR：平方损失光滑、可微，便于基于梯度的训练 | 一致 |
| 三 | w 是权重，b 是偏置，合称参数，训练时学出来 | MLCC-LR；D2L-LR：偏置是所有特征为 0 时的预测值 | 一致 |
| 四 · `ml02a-nudge-story` | 「挪一点看损失怎么变」就是导数，表示坡度 | D2L-CALC：导数是 (f(x + h) − f(x)) / h 在 h → 0 时的极限，是瞬时变化率，也就是函数在这一点的斜率 | 一致；页面用 h = 0.1 的数值近似，折叠块里给出解析导数 14(w − 3) |
| 四 · 折叠块 | 两边各挪一次再相除，误差更小 | CS231N：建议用中心差分 (f(x + h) − f(x − h)) / 2h；单边差分误差是 O(h)，中心差分是 O(h²) | 一致 |
| 四 | 有几个参数，就各量一个坡（固定其他参数） | D2L-CALC：梯度是由偏导数组成的向量；求偏导时，其他变量当作常数 | 一致 |
| 四 | 坡度为负 → 把 w 调大 | MLCC-GD：新权重 = 旧权重 − 小步长 × 坡度，往负坡度方向走 | 一致 |
| 四 · 折叠块 | 实际程序用导数公式算梯度，第 08 章讲怎么对很多参数一次算完 | D2L-BP：反向传播就是计算神经网络参数梯度的方法 | 一致 |
| 五 · `ml02a-descent` | 新的 w = 旧的 w − η × 坡度，叫梯度下降 | MLCC-GD；D2L-LR：(w, b) ← (w, b) − η · 梯度（小批量平均） | 一致；页面用全部 3 单求平均，不是小批量 |
| 五 · `ml02a-lr-steps` | 学习率太大会越跳越远，太小走得很慢 | MLCC-HP：太大时在最小值附近来回弹、不收敛；太小时要很久才收敛 | 一致 |
| 六 | 代码的梯度：grad_w = 平均（2 × (预测 − 实际) × x） | MLCC-GD：∂/∂w = (1/M) Σ (f(x) − y) · 2x | 一致；代码注释说明「预测 − 实际」正好是残差的相反数 |
| 七 · 术语表 | 残差、损失函数、梯度、梯度下降、学习率、训练 | NIST、MLCC-LOSS、MLCC-GD、MLCC-HP、D2L-CALC | 一致 |
| 全页 · 术语弹窗 | 「残差」弹窗原来显示的是「残差连接」的解释 | 本页 `lesson-glossary` 覆盖为回归里的残差（NIST 定义） | 已修正；03、03b 同样处理 |
