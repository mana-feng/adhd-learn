## 知识点 → 来源

| 节 / 图 | 知识点 | 来源与原文要点 | 页面写法 |
|---|---|---|---|
| 一 · `ml03-plug-in` | 多特征线性规则：每个特征一个权重，再加偏置 | MLCC-LR 给出多特征公式 y′ = b + w₁x₁ + … + w₅x₅；SK-LM 给出 ŷ = w₀ + w₁x₁ + … + wₚxₚ | 一致，用 ŷ = w₁x₁ + w₂x₂ + w₃x₃ + b |
| 一 | 权重、偏置都是训练中学到的参数 | MLCC-LR：权重和偏置都是模型参数，在训练中算出 | 一致 |
| 一 | 是 / 否特征记成 1 / 0 | MLCC-OH：类别特征转成数字向量，取值为 1.0 或 0.0；只有两个类别的例子是 snowed_today | 一致；下雨只有两个类别，用一个 0/1 列表示 |
| 二 · `ml03-weight-meaning` | 权重表示「其他特征不变时」的关系 | SK-COEF：系数表示假设其他特征都不变时，这个特征和目标的关系（条件依赖） | 一致；用 B、D 两单只差下雨来演示 |
| 二 | 单位不同，原始权重不能直接比大小 | SK-COEF：特征的单位、取值范围不同，不能直接比较系数大小 | 一致 |
| 二 | 权重不是因果结论 | SK-COEF：线性模型衡量的是统计关联，谈因果要谨慎，相关不等于因果 | 一致；两种原因的示意图是本课自编的例子 |
| 三 · `ml03-grad-table` | 训练四步：算损失 → 定方向 → 挪一小步 → 重复 | MLCC-GD 原文列出这四步 | 一致 |
| 三 | 残差 = 实际 − 预测；权重的坡度 = 平均（−2 × 残差 × 特征值），偏置看作特征值 1 | NIST：残差 = 观测值 − 预测值。MLCC-GD：∂/∂w = (1/M) Σ (f(x) − y) · 2x，其中 f(x) − y = −残差 | 一致（2026-11-09 起采用标准残差定义，所以多一个负号；图里解释了负号的意思） |
| 三 | 「两边各挪一点」量坡度 | 数值验证：表里的数用 `svgs_03.check_numbers()` 复算，和解析式一致 | 教学用的数值近似，正式方法见 MLCC-GD 的导数公式 |
| 四 | 各列范围差很多时梯度下降收敛慢，标准化能加快收敛 | MLCC-NORM：范围不匹配会让梯度下降来回弹、收敛变慢；归一化帮助模型更快收敛，也帮助模型学到合适的权重。SK-PRE：方差大好几个数量级的特征会主导目标函数 | 一致。「排队坡度是下雨的 6 倍」只是第一步的一个例子，不是严格原因 |
| 四 · `ml03-standardize-how` | z = (x − 平均) ÷ 标准差；z 表示离平均几个标准差 | MLCC-NORM：Z-score 是一个值离平均有几个标准差，x′ = (x − μ) / σ。SK-SS：z = (x − u) / s | 一致 |
| 四 · 折叠「标准差怎么算」 | 标准差除以 n（不是 n − 1） | SK-SS：使用有偏估计，等价于 `numpy.std(x, ddof=0)` | 一致；6 单除以 6 |
| 四 · `ml03-scale-compare` | 560 步 / 9 步、学习率 0.05 / 0.3 | 本页代码 `code03.py` 的实测输出 | 是本页实验结果，不是外部结论 |
| 四 · 学习率 | 太大会发散，太小收敛慢 | MLCC-HP：太大时在最小值附近来回弹、不收敛；太小时要很久才收敛 | 一致 |
| 四 · 附带好处 | 原权重 × 标准差后单位一致，可以比较 | SK-COEF：系数乘以对应特征的标准差，就换成同一单位，可以比较 | 一致 |
| 四 · 提醒 | 平均值、标准差只用训练数据算，否则是数据泄漏 | SK-PIT：不要在测试数据上 fit；预处理只从训练数据学，例子正是「除以平均值」。SK-SS：统计量从训练集算出，再用于之后的数据 | 一致 |
| 四 · 提醒 | 树模型通常不需要标准化 | SK-TREE：需要的数据准备很少，其他方法常常需要归一化 | 一致 |
| 五 | `LinearRegression` 最小化误差平方和，一次求解 | SK-LM：最小化残差平方和 min‖Xw − y‖²，用 X 的奇异值分解求解，成本 O(n·p²)；系数存在 `coef_`、`intercept_` | 已改成「用线性代数一次求出」（原写「用公式直接解出」，不准确） |
| 五 | 样本很多时改用 SGD，SGD 对尺度敏感 | SK-SGD：`SGDRegressor` 适合训练样本多（大于 10,000）的回归问题；SGD 对特征尺度敏感，强烈建议缩放 | 已按原文改写（原写「数据量、特征数很大时」） |
| 六 · `ml03-line-limit` | 线性规则画不出弯曲 / 跳变；办法是造新特征或换模型 | MLCC-FC：特征组合和多项式变换让线性模型能处理非线性；神经网络可以自动找特征组合。SK-TREE：树是分段常数近似，用 if-then-else 规则逼近曲线 | 一致；5 km 换骑手的数据是自编示例 |
