B03 · 梯度下降：从变化率到参数更新

⏱ 阅读约 19 分钟 · 动手实践另计

明明已经知道预测错了 3 分钟，模型为什么还需要“梯度”？

因为知道“错多少”并不等于知道“参数往哪边调”。这一课把上节的损失变成可以反复执行的调整规则，从手动尝试、小幅试探、真正求导，再到一次可验证的参数更新。

学完后你能完整解释：预测 → 损失 → 导数/梯度 → 学习率 → 更新 → 新预测；能手算 w 与 b 的梯度，指出学习率过大的危险。

前置：02a 已用试探法改参数，03 学过 ŷ = wx+b，03b 学过残差与平方损失。无需先学完微积分。下一步：03a 会把这条训练闭环用到二分类。

一、知道预测错了，不代表知道怎么改

继续使用一份人为构造的外卖订单。配送距离记为 x=3（数值表示 3 km），实际送达时间 y=20 分钟。我们先使用规则 ŷ=wx+b，其中 w=5（每公里增加约 5 分钟），b=2 分钟。代入 ŷ=5×3+2=17 分钟，预测比实际少 3 分钟。

我们选单样本平方误差 L=(ŷ−y)²：L=(17−20)²=9 分钟²。记号 L 是需要尽量变小的训练损失，不是模型的最终评估分数。

问题来了：提高 w 还是降低 w？提高 b 还是降低 b？分别调整多少？如果随便乱挪，只能靠运气。梯度让这个方向可以计算。

二、先不求导：把权重挪一小步

先让 b=2 不变，只调整权重 w。每次改变 0.1：

权重 w预测 ŷ=3w+2损失 (ŷ−20)²
4.916.710.89
5.017.09.00
5.117.37.29

从 4.9 → 5.1，损失减小了 10.89−7.29=3.60。平均每增加 1 单位权重，损失变化约为 (7.29−10.89)/(5.1−4.9)=−3.60/0.2=−18。

这里的 −18 是损失随权重变化的斜率（在本例恰好等于中点处的精确导数，因为损失是二次函数）。负号说明：在目前这个位置，适量增加权重可以减小损失；但不能无限制地增加。

三、导数和梯度：让“试探”变成计算

导数可以看成“把试探步长缩得非常小时的变化率”。例如 dL/dw 读作“L 对 w 的导数”，表示我们仅改变权重 w 时，损失变化有多快。

我们有两个参数 w、b，因此分别求偏导数，把它们合起来就是梯度 ∇L=[∂L/∂w, ∂L/∂b]。求 ∂L/∂w 时，把 b 当常量；反过来求 ∂L/∂b 时把 w 当常量。

先引入一个中间变量：e = ŷ − y，也就是预测减实际。在 03b 中采用的残差是 r=y−ŷ，所以这里 e=−r，不能把两个符号直接混用。

先从函数链看来源：

ŷ = wx+b → e=ŷ−y → L=e²

∂L/∂ŷ = 2(ŷ−y) = 2e

∂ŷ/∂w = x，∂ŷ/∂b = 1

所以用链式法则（相邻变化率相乘）：

∂L/∂w = (∂L/∂ŷ)(∂ŷ/∂w) = 2e·x

∂L/∂b = (∂L/∂ŷ)(∂ŷ/∂b) = 2e

“平方的变化率是两倍原值”即 d(e²)/de=2e；“w 每增 1，ŷ=wx+b 增加 x”即 ∂ŷ/∂w=x。这两条组合，就解释了为什么梯度公式中会出现 2、误差 e 和特征 x，不是硬背出来的。

四、一次完整数字代入

本例仍是 x=3、y=20、w=5、b=2，单样本平方损失（注意这里没有额外除以样本数）。每个变量含义和单位已在前面给出：

步骤公式数字代入说明
第一步：预测ŷ = wx + b5 × 3 + 2 = 17分钟
第二步：误差e = ŷ − y17 − 20 = −3分钟
第三步：损失L = e²(−3)² = 9分钟²
第四步：损失对预测的导数∂L/∂ŷ = 2e2 × (−3) = −6分钟
第五步：损失对权重的导数∂L/∂w = (2e)x(−6) × 3 = −18按特征单位变化
第六步：损失对偏置的导数∂L/∂b = 2e−6 × 1 = −6按偏置单位变化

于是当前梯度 ∇L=[−18, −6]。它告诉我们：在目前参数附近，增加 w 和增加 b 都会让这一条样本的损失减小。不过梯度来自当前这一条样本，它不保证改完对所有订单都更好。

五、学习率：沿下降方向走多远

梯度的方向指向损失增长最快的局部方向。为了让损失下降，我们沿负梯度更新：

w_new = w_old − η(∂L/∂w)

b_new = b_old − η(∂L/∂b)

η（读作 eta）是学习率，控制步长。本例用 η=0.01 演示数值更新（本例只是以数值尺度做计算，真实任务要根据特征缩放与参数单位选择合适步长）。

w_new = 5−0.01×(−18)=5.18，b_new = 2−0.01×(−6)=2.06。

再预测：ŷ_new=5.18×3+2.06=17.60；新损失 L_new=(17.60−20)²=5.76，确实比原来 9 小。

六、动手改变步长，观察损失

下面的实验从相同的初始权重和偏置开始，每一步都重新计算梯度。滑块调整学习率和步数；第一步的梯度始终是 [−18, −6]，但第二步以后会随着参数改变。

初始损失9.000
更新后损失5.760
最新 w / b5.180 / 2.060
最新预测（分钟）17.600

η=0.010，执行 1 步：损失从 9.000 降至 5.760。学习率不是越大越好。

试一试：将学习率改为 0.100、步数设为 2。你会发现更新后可能回到原损失，无法进步；再把学习率调到 0.200，损失会迅速发散。并非梯度算错了，而是每一步跨得太远。

为什么 0.05 刚好一步到零损失？本例只有一条样本、一个简单二次损失，属于特殊情况；在真实多样本、非凸目标中没有这种普适值。

七、真正训练时不是只看一条订单

有 n 条样本时，常用平均平方损失 MSE = (1/n) Σ(ŷᵢ−yᵢ)²。因此对权重求导也要平均：∂MSE/∂w = (2/n) Σ(ŷᵢ−yᵢ)xᵢ；偏置梯度为 (2/n) Σ(ŷᵢ−yᵢ)。Σ 表示对 i=1,…,n 的订单求和。n=1 时就回到前面的例子。

这里如果把多条不同距离的样本一起训练，模型必须同时兼顾这些样本，而不只是把某一单完美拟合。如何检验泛化，请回看 A04 的数据集划分 与后面的 评估与过拟合。

# 只有 Python 标准库；与上面单样本实验完全一致
x, y = 3.0, 20.0
w, b = 5.0, 2.0
eta = 0.01

for step in range(3):
    prediction = w * x + b
    error = prediction - y
    loss = error ** 2
    print(step, round(prediction, 4), round(loss, 4))
    dw, db = 2 * error * x, 2 * error
    w -= eta * dw
    b -= eta * db

# step=0: 17.0, 9.0；step=1: 17.6, 5.76；step=2: 18.08, 3.6864

打印的是每次更新之前的预测和损失；所以第 2 行的输出是第一步更新后的结果。代码采用的是单样本平方损失，如果改成 0.5×e²，梯度会整体缩小一半，学习率和数值变化也会不同。

八、检查自己能否独立算一遍

  1. 为什么 e=ŷ−y 与 03b 的残差 r=y−ŷ 符号相反？
  2. x=3、y=20、w=5、b=2 时，损失对权重的梯度为什么是 −18，而不只是 −6？
  3. 学习率过大时，损失不断增加，是不是一定要换一种损失函数？
展开答案与逐步解释

① 两种误差定义只差一个负号；求导时要坚持约定，不混用。② ∂L/∂ŷ=2(17−20)=−6，而 ∂ŷ/∂w=x=3，按链式法则得到 −6×3=−18。③ 不一定，先检查特征尺度、梯度和学习率；在本例中把 η 调小即可恢复下降。

可以停在这里：如果你能手算一次“当前梯度 → 更新参数 → 新损失”，就已经掌握了神经网络训练也会用到的最重要闭环。
