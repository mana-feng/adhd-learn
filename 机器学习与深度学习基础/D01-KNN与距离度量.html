D01 · KNN：邻居投票与距离度量

⏱ 阅读约 16 分钟 · 动手实验另计

如果暂时不想学习预测公式，能不能找几张最相似的历史订单，让它们投票？

KNN（K-Nearest Neighbors）把“相似样本可能有相似标签”变成可计算的步骤：定义距离、挑选 K 个近邻、投票决定类别。它的原理容易理解，但要真正用好，需要考虑尺度、K 的选择、数据维数和预测成本。

学完能独立算距离与 K=1、3、5 的投票，知道 KNN 回归与分类如何不同，能解释为什么特征工程会改变邻居，并能运行一份 sklearn 代码。

前置：A04 · 数据与标签、C01 · 指标、C05 · 数据处理。下一节：先进入 决策树；概率分类专篇将在下一次补充。

一、先有训练样本，再谈“相似”

在新订单下单时，模型要预测它是否会超过承诺的 30 分钟。本例只用一个特征：配送距离 x，单位是公里。历史订单送达后已经有标签 y=1（超时）或 y=0（准时）。五条数据都是人为构造的演示数据，不代表真实外卖配送规律。

现在来了一张距离 x_new=5 km 的新订单，真实标签还未知：

历史订单距离 km真实标签与 5 km 的差距
A2.0准时 03.0
B3.0准时 02.0
C4.6超时 10.4
D6.1准时 01.1
E7.4准时 02.4

和线性回归的 ŷ=wx+b 不同，最简单的 KNN 并不在训练阶段求出这两个参数。它会保存训练样本，在预测新订单时比较新旧样本的距离。

二、距离是怎样计算出来的

只有配送距离这一列时，用绝对差值就够了：d(x_new,x_i)=|x_new−x_i|。符号 d 表示两单相差多远；x_i 是第 i 张历史单的公里数。

新单 5 km，与 C 单 4.6 km 相距 |5−4.6|=0.4 km；与 D 单 6.1 km 相距 |5−6.1|=1.1 km。完整排序是 C(0.4) → D(1.1) → B(2.0) → E(2.4) → A(3.0)。

如果同时比较距离和商家排队单数，就有两个特征。数值欧氏距离可写成 d=√[(x₁−a₁)²+(x₂−a₂)²]；x₁,x₂ 是新订单特征，a₁,a₂ 是历史订单对应特征。假设两单分别为 (5 km,4 单) 和 (4 km,3 单)，数值距离为 √(1²+1²)=√2≈1.414。但公里与排队单数的单位不同，这样直接混算只是演示，不代表合理的业务相似度。

三、K=1 和 K=3 为什么会给出相反结论

按照上面的近邻顺序：

选择 K参与投票的订单准时 / 超时票数预测类别
K=1C0 / 1超时 1
K=3C、D、B2 / 1准时 0
K=5C、D、B、E、A4 / 1准时 0

K 太小，单个噪声样本可能改变结果；K 太大，模型可能忽略附近的差异。二分类常用奇数 K 来减少投票平局，但两个样本到查询点距离相同仍要有固定的排序策略。在实际任务中，K 应在验证集上选择，而不是看完测试答案再挑。

五、为什么 KNN 特别在乎特征工程

如果同时使用公里（1～10）与价格（几十到几百元）计算欧氏距离，价格数值范围可能主导“相似度”，即使它对业务不是最重要的。我们通常要先使用 C05 · Pipeline，只用训练数据估计缩放参数，再用于验证和测试数据。缩放不是万能的，应该考虑字段含义和实际任务。

其他局限还有：① 无关特征会干扰邻居选择；② 高维空间中距离差异可能难以区分样本（维度灾难）；③ 原始 KNN 预测时可能需要比较大量训练样本，数据量变大后要考虑索引结构或近似近邻；④ 类别非常不均衡时，多数投票可能偏向频繁类别。

六、如果标签是分钟数，KNN 就可以做回归

如果把分类标签换成“历史真实送达分钟”，最简单的 KNN 回归会把最近 K 位邻居的目标值取平均。例如三位邻居真实用时为 22、25、31 分钟，则预测为 (22+25+31)/3=26 分钟。距离加权版本会给近邻更高权重，但需要明确具体的权重公式。

from sklearn.neighbors import KNeighborsClassifier

X_train = [[2.0], [3.0], [4.6], [6.1], [7.4]]
y_train = [0, 0, 1, 0, 0]

model = KNeighborsClassifier(n_neighbors=3)
model.fit(X_train, y_train)
print(model.predict([[5.0]]).tolist())  # [0]
distances, indices = model.kneighbors([[5.0]])
print(indices[0].tolist())             # [2, 3, 1] => C D B
print(distances[0].round(1).tolist())  # [0.4, 1.1, 2.0]

这里只有一个特征，因此缩放不改变邻居的相对次序。多特征时请把合适的编码和缩放放入 Pipeline。KNN 在训练集表现很好并不意味着能泛化，要使用独立验证集。

七、检查点

  1. 新订单为 5 km，K=1 与 K=3 的结果为什么不同？
  2. KNN 中的 fit 与线性回归中的参数学习有什么区别？
  3. 价格远大于公里数时，直接按欧氏距离可能导致什么问题？
展开答案

① K=1 只听超时单 C 的标签，预测超时；K=3 听 C、D、B，多数为准时。② 最基本的 KNN 保存训练样本，预测时检索近邻；线性回归通过训练估计权重。③ 一个特征数值范围可能主导距离，应该在训练集内部拟合合理的缩放与特征处理。
