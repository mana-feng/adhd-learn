05 · 评估与过拟合

⏱ 24 分钟 ｜ ⭐⭐ 全教程最重要的一章

如果你这份教程只学一章，学这章。 模型算法会过时，「怎么知道模型到底行不行」这件事永远不会过时。

🎯 一句话

机器学习里 90% 的翻车，不是模型不好，而是你以为的好是假的。这一章教你怎么不骗自己。

⚖️ 一、偏差-方差：过拟合的根源

  • 第 1 章的深度表能看出“复杂度变高时训练分、测试分怎么变”，但单次分数不是偏差、方差各项的实测值
🔎 细节：这张曲线不是普遍定律
  • 平方损失下，对训练集和噪声取期望，期望误差可以严格分解为偏差²、方差与不可约噪声
  • 实际的验证曲线也可能出现“双降”等形态，不一定是 U 形
  • 正则、剪枝或早停要用验证结果去选；不能从图上保证最低点怎样移动

延伸 → 《机器学习的数学原理》第 8 章：严格推导这个等式，并解释集成学习为什么有效

怎么判断自己在哪一侧：

现象 诊断 怎么办
训练集也差 欠拟合（高偏差） 加模型复杂度、加特征、减正则、训久点
训练好、测试差 过拟合（高方差） 加数据 ⭐、加正则、减复杂度、早停
两边都好 ✅ 收工 —
训练集差但测试集好 🤨 有 bug 或数据泄漏 查代码

例：第 1 章不限深度的树，训练 100%、测试 91.8% → 训练好、测试差 → 在过拟合一侧，先试限制深度，或加数据。

💡 增加有代表性且标签可靠的数据可能改善泛化；是否优先采集，要结合学习曲线、分布、成本与验证结果。

🔄 二、交叉验证：别信单次切分

单次切分的分数带着运气。差距比这份运气波动还小时，别下“A 比 B 好”的结论。

K 折交叉验证

  • 把数据切成 K 份（常用 5 或 10），轮流拿 1 份当验证、其余 K − 1 份训练
  • 得到 K 个分数，报告均值 ± 标准差
  • 每个样本都当过一次验证，比单次切分稳；代价是要训练 K 次

变体，选对了才有意义：

类型 什么时候用
KFold 普通情况
StratifiedKFold ⭐ 分类任务默认用它——保证每折的类别比例一致
GroupKFold 同一个用户/病人有多条数据时，防止同组数据跨折泄漏
TimeSeriesSplit ⭐ 时间序列必须用——只能用过去预测未来

延伸 →

  • Kaggle 第 1 章：验证集怎么构造；CV 划分和线上 / 测试场景不一致，是竞赛掉分的头号原因
  • 推荐算法第 3 章「按时间切分，别随机切」：就是 TimeSeriesSplit 的思想

💀 三、数据泄漏：最致命的错误

数据泄漏：训练时用到了预测那一刻本不该知道的信息。症状是离线分数虚高，上线就垮。

🔨 一个会让你后背发凉的实验

import numpy as np
from sklearn.model_selection import cross_val_score, KFold
from sklearn.linear_model import LogisticRegression
from sklearn.feature_selection import SelectKBest, f_classif
from sklearn.pipeline import make_pipeline

rng = np.random.RandomState(0)
X = rng.randn(200, 5000)        # 200 个样本，5000 个【纯随机噪声】特征
y = rng.randint(0, 2, 200)      # 标签也是【纯随机】的
# → 特征和标签毫无关系，任何诚实的模型准确率都该是 50%

# ❌ 错误做法：先用全部数据选特征，再做交叉验证
sel = SelectKBest(f_classif, k=20).fit(X, y)
bad = cross_val_score(LogisticRegression(max_iter=2000),
                      sel.transform(X), y, cv=KFold(5, shuffle=True, random_state=0))

# ✅ 正确做法：把特征选择放进 Pipeline，在每折内部重新做
pipe = make_pipeline(SelectKBest(f_classif, k=20), LogisticRegression(max_iter=2000))
good = cross_val_score(pipe, X, y, cv=KFold(5, shuffle=True, random_state=0))

print(f"❌ 先选特征再CV：{bad.mean():.1%}")
print(f"✅ 放进Pipeline：{good.mean():.1%}")

实测结果：

算一算

❌ 先选特征再CV：76.5% ← 纯噪声数据上凭空刷出 76.5%！

✅ 放进Pipeline：47.5% ← 诚实（≈50% 随机水平）

💡 发生了什么：先用全部数据挑特征，等于偷看了所有标签。

  • 5000 个噪声特征里，总有一些碰巧和标签相关
  • 挑出来的 20 个把标签信息“记”了进来
  • 之后交叉验证怎么切都逃不掉

🔑 会看到 y、或会统计全体数据的步骤，都放进 Pipeline，在每折内部重新执行：

  • 会看到 y：特征选择、目标编码
  • 会统计全体：标准化、缺失值填充
  • 会造样本：过采样
🔎 细节：过采样放进哪种 Pipeline
  • scikit-learn 自带的 Pipeline，中间步骤要有 fit / transform；会改变样本数的重采样器放不进去
  • 过采样（如 SMOTE）用 imbalanced-learn 的 Pipeline：只在训练时重采样，验证和预测时原样通过

常见泄漏清单

泄漏形式 例子
预处理泄漏 ⭐ 用全量数据 fit scaler / 选特征 / 填缺失值
时间泄漏 ⭐ 用未来数据预测过去（推荐算法第 3 章的坑）
分组泄漏 同一用户的数据同时出现在训练和测试集
目标泄漏 特征里混进了标签的衍生物（如「是否退款」预测「是否投诉」）
重复样本 去重没做干净，同一条数据两边都有

⚠️ 样本彼此“同源”时，随机划分测的是记忆，不是泛化。

  • 同源：同一用户的多条记录、同一家族的多条蛋白序列
  • 随机切会把几乎一样的东西分到训练、测试两边
  • 科学问题怎么变成模型 07 · 评测的坑：同一份数据只改划分方式，R² 从 0.707 掉到 −1.199（负数 = 还不如猜均值）

📏 四、选对指标（准确率是个陷阱）

🔨 实测：99% 的准确率毫无意义

数据：1.6% 的正样本（如欺诈检测、罕见病）

算一算

方案 准确率 精确率 召回率 F1 AUC PR-AUC

全predict 0(傻子) 98.4% 0.0% 0.0% 0.0% 0.50 0.016（若按AP）

逻辑回归(默认) 98.4% 0.0% 0.0% 0.0% 0.65 0.07

+ class_weight平衡 67.7% 2.7% 55.3% 5.1% 0.62 0.04

默认模型 阈值=0.1 98.1% 17.6% 6.4% 9.4% 0.65 0.07

默认模型 阈值=0.05 95.4% 10.3% 25.5% 14.7% 0.65 0.07

三个必须看懂的点：

  1. 傻子模型和逻辑回归准确率一样（98.4%）：准确率分不出它们
  2. AUC 0.65 说明模型有信号，但默认阈值 0.5 下一个正例都没抓到
  3. 正例稀少时，PR 类指标更直接反映精确率与召回率的取舍；ROC-AUC 看排序。按业务代价选，没有哪个天生更“诚实”

指标速查

指标 含义 什么时候用
准确率 对的比例 类别均衡时。⚠️ 不平衡时是陷阱
精确率 Precision 说是正的里面真的有多少 误报代价高（如垃圾邮件误杀）
召回率 Recall 真的正的里面抓到多少 漏报代价高（如癌症筛查）⭐
F1 精确率和召回率的调和平均 两者都要
ROC-AUC 随机取一正一负：正例分数更高计 1，并列计 0.5 衡量排序，不直接衡量概率校准
PR-AUC / AP（注明算法） PR曲线的汇总；AP与梯形面积不是同一算法 正类稀少且关注正预测质量时常用；按目标选指标，不预设PR永远更优

同一张混淆矩阵，把分母写出来

只讨论二分类、正类记为 1。格子名字这样读：T / F = 预测对没对，P / N = 预测成正还是负。

$$P=\frac{TP}{TP+FP}=\frac{30}{50}=0.6,\qquad R=TPR=\frac{TP}{TP+FN}=\frac{30}{40}=0.75$$

$$F_1=\frac{2TP}{2TP+FP+FN}=\frac{60}{90}=\frac23,\qquad FPR=\frac{FP}{FP+TN}=\frac{20}{60}=\frac13$$

⚠️ 分母为 0 时（比如没有任何样本被预测为正），要写明用的 zero_division 规则和各类样本数，不能把“没定义”当成满分。

从一个阈值到整条曲线

  • ROC：横轴假正率 FPR，纵轴真正率 TPR（= 召回率）
  • PR：横轴召回率，纵轴精确率
  • 两条曲线都要扫过很多阈值才画得出，一张混淆矩阵推不出 AUC 或 AP

AUC 的人话读法：随机抽一个正例、一个负例，模型给正例打分更高的概率。

  • 分数并列算半分：一正一负、分数相同时 AUC = 0.5，不是 0
  • 分数乘 100 再加 5 这类严格递增的变换不改排序，AUC 也不变
  • 所以 AUC 相同 ≠ 概率同样可信，校准要另外查

🔎 细节：正类比例、抽样前提、AP 与 PR-AUC、并列分数

ROC点一样，precision也可能不同

记正类比例为π，在固定模型且给定阈值的TPR/FPR不变时：

$$Precision=\frac{\pi\,TPR}{\pi\,TPR+(1-\pi)\,FPR}$$

原表π＝0.4、TPR＝0.75、FPR＝1/3，得到P＝0.6。若只把负类每项等权重复6次，TP/FN仍为30/10，FP/TN变为120/240：π＝0.1，TPR与FPR不变，而P＝30/150＝0.2。这是分层重加权手算，不是新采集或重训实验。

“改负样本比例，AUC 变不变”要带前提

  • 固定模型分数，评估时只在每类内无偏随机抽样、类条件分数分布不变：总体 ROC 与成对排序 AUC 不因正类比例本身改变
  • 有限样本的估计仍会波动
  • 换成难负例、改变负类子群或候选池、按分数挑样本、用新比例重训：都不再是同一前提，要重新评估并写清抽样口径

AP 与“PR-AUC”不能只对名字

  • scikit-learn 的 AP 按每次召回增量给 precision 加权，和对 PR 点直接做梯形积分不同
  • 比较时写清实现、正类、评估样本 / 权重和抽样方式
  • 常数得分的 AP 等于正例比例，上表约 0.016；上表其余 PR-AUC 数字原稿未注明积分方式，保留作记录、未复验

经验 ROC 与并列分数

  • 常见的经验 ROC 用线段连接各点时，曲线下面积等于上面的成对排序分数（并列计半分）
  • 附录 C 第 9 题用平均秩实现，复杂度 $O(n\log n)$；树模型同一片叶子的样本分数并列，尤其要注意
  • 非严格单调的变换如果制造了新的并列，AUC 可能改变，不能照搬
  • F1 不用 TN，也不会自动反映误报、漏报各自的代价
📚 指标定义与ROC/PR关系

依据 scikit-learn指标指南、混淆矩阵轴、P/R/F与零分母、ROC-AUC分数输入、AP实现及Davis与Goadrich的原始ROC/PR论文；这里的整数例只演示定义与条件，不声称任何模型的真实质量。

阈值不是 0.5

模型输出的是分数，阈值把它变成 0 / 1。0.5 没有特殊地位。

  • 调阈值不用重训，却能大幅改变精确率和召回率的平衡
  • 分数未必是校准过的概率，“大于 0.5 才算正”只是默认习惯
  • 怎么选：先定业务底线（例如召回率至少 80%），再在验证集上找满足底线、精确率最高的阈值
  • 阈值只能用验证集，或 OOF 预测（交叉验证里每个样本当验证时拿到的预测）来选；定下后才在测试集上评估一次

📈 五、学习曲线：加数据有用吗

怎么读：差距和趋势只是线索，用来决定下一步先试什么。

  • 差距大、验证分还在涨 → 加数据可能有用，先小规模验证收益
  • 差距大、验证分已平 → 先试正则、剪枝或降低复杂度
  • 两条线都低、贴在一起 → 欠拟合：加特征，或换更强的模型
  • 平台期还要排查优化过程和数据分布；探索时用验证集，不用测试集

单选1. 训练集上分数就很差，你在偏差—方差的哪一侧？

看答案与解析

答案：C

偏差=模型太简单，训练集就差（欠拟合）；方差=对训练数据太敏感，训练好测试差（过拟合）。看训练集分数：训练集也差就是欠拟合，训练好测试差就是过拟合。

单选2. 同一模型只换切分种子，10 次结果的实测范围是？

看答案与解析

答案：D

带很大运气成分。实测同一模型只换切分种子，10 次结果在 94.7%~98.2% 之间，极差 3.5%。

单选3. 分类任务和时间序列默认该用哪种交叉验证？

看答案与解析

答案：B

分类用 StratifiedKFold（保持类别比例）；时间序列必须用 TimeSeriesSplit（只能用过去预测未来）。

单选4. 纯噪声实验里，特征选择放在交叉验证外（错误）和放进 Pipeline（正确）的准确率分别是？

看答案与解析

答案：B

因为特征选择会"看到"全部标签，把标签信息记进选中的特征里。纯噪声实验：错误做法 76.5%，正确做法 47.5%。

判断5. 正样本只占 1.6% 时，98.4% 的准确率说明模型已经很好。

看答案与解析

答案：错误

什么都说明不了——全预测多数类的傻子模型也是 98.4%。该看 PR-AUC、F1、召回率，并且调阈值。

单选6. 学习曲线怎么帮你判断「该加数据还是该改模型」？

看答案与解析

答案：C

用验证集学习曲线提出假设：仍上升可检验加数据收益，平台期继续查模型、特征、优化与分布；不能由平台断言更多数据无用。

单选7. 为什么最终测试集只能用一次？

看答案与解析

答案：A

反复在测试集上调参会造成慢性泄漏，测试集逐渐变成"第二个训练集"，失去无偏评估的意义。

单选8. 验证集上 TP = 8、FP = 2、FN = 8、TN = 82。精确率、召回率、准确率各是多少？

看答案与解析

答案：C

精确率 8 / (8 + 2) = 0.8；召回率 8 / (8 + 8) = 0.5；准确率 (8 + 82) / 100 = 0.9 —— 准确率很高，却漏掉了一半正例。

⚡ 走神救援

先记住这几件事

  • 验证集负责选方案，最终测试集负责检验泛化，不能反复拿测试集调参。
  • 预处理只在训练部分拟合；时间、用户等分组关系也必须体现在划分里。
  • 结合训练与验证曲线判断欠拟合、过拟合，再调整容量、正则化或数据。
  • 指标必须对应实际任务；保留基线并观察不同划分或种子的波动。
