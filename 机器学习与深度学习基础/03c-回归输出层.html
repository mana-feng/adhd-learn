03c · 回归输出层：模型应该输出什么

⏱ 阅读约 23 分钟 · 动手实践另计

模型算出 −5 分钟，是程序算错了吗？

线性模型会产生任意实数。真实任务却可能只允许正数、概率或有限区间。输出映射负责把模型的原始数值变成任务需要的预测，但它也会改变梯度，不能只按“看起来合理”选择。

学完后，你能根据目标范围比较恒等映射、Softplus、Sigmoid 与缩放 Sigmoid，并解释训练内 clamp 为什么可能挡住梯度。

前置连接：需要 03b 的梯度与链式法则，以及 03a 对 Sigmoid 的第一次认识。本章仍是普通数值回归；使用 Sigmoid 不会自动把任务变成分类。

1. 原始输出为什么会是负数

线性模型先计算：

$$z=wx+b$$

x 是输入特征，w 和 b 是模型参数，z 是尚未解释成最终预测的原始输出。假设配送距离 x=2 km，当前 w=-3 min/km、b=1 min，就得到 z=-3×2+1=-5。

计算本身没有出错：实数相乘再相加当然可以得到负数。问题是模型还没学好，或者我们没有把“送达时间必须大于 0”这一任务知识放进输出方式。于是把最终预测写成：

$$\hat y=f(z)$$

f 是输出映射。它决定 z 能被变成哪些合法预测，也通过链式法则加入训练路径：

$$\frac{\partial L}{\partial z}=\frac{\partial L}{\partial\hat y}\frac{\partial\hat y}{\partial z}$$

第二项就是映射的斜率。范围限制和梯度行为必须一起看。

2. 恒等映射：不限制范围

最简单的映射是什么也不改变：

$$\hat y=f(z)=z$$

它叫恒等映射，因为输入什么就输出什么；导数 dŷ/dz=1，梯度原样传回。温度变化、利润涨跌、坐标偏移等目标可以为任意实数，通常从恒等映射开始。03 的线性回归也使用它。

优点是不会饱和，也允许模型外推；限制是不会自动阻止不合业务范围的预测。若送达时间暂时算出 −5，可以先检查数据、训练和验证表现；是否加入正值映射取决于“正值约束是否真的必须进入模型”。

3. Softplus：平滑地得到正数

送达时间、价格、尺度参数等常要求严格大于 0。Softplus 定义为：

$$\operatorname{Softplus}(z)=\log(1+e^z)$$

对任何有限实数 z，指数 e^z 始终大于 0，因此 1+e^z>1，它的自然对数就大于 0。所以 Softplus 输出严格为正。

完整代入三个值（四舍五入到 4 位小数）：

z e^z 1+e^z log(1+e^z)
-2 0.1353 1.1353 0.1269
0 1 2 0.6931
3 20.0855 21.0855 3.0486

Softplus 的导数恰好是 Sigmoid：

$$\frac{d}{dz}\log(1+e^z)=\frac{e^z}{1+e^z}=\frac{1}{1+e^{-z}}=\sigma(z)$$

因此斜率在 0 与 1 之间。z 很负时，输出接近 0，梯度也接近 0；z 很正时，Softplus 接近 z，斜率接近 1。

它和 ReLU 不同：ReLU 是 max(0,z)，负半轴输出精确为 0 且梯度通常为 0，零点还有折角；Softplus 在所有有限 z 上光滑且输出大于 0，但很负时仍会出现小梯度。数值实现应使用框架的稳定版本，而不是直接拼指数。

4. Sigmoid 与缩放 Sigmoid

普通 Sigmoid 是：

$$\sigma(z)=\frac{1}{1+e^{-z}}$$

分母始终大于 1，所以有限 z 的输出严格落在 (0,1)。z=0 时输出 0.5；正负两侧逐渐贴近 1 和 0，形成 S 形。

它的导数来源可以逐步写成：令 s=σ(z)，对 (1+e^{-z})^{-1} 求导，得到

$$\sigma'(z)=\frac{e^{-z}}{(1+e^{-z})^2}=\sigma(z)(1-\sigma(z))=s(1-s)$$

当 s 接近 0 或 1，s(1-s) 接近 0，这叫饱和：即使损失想大幅改变预测，映射这一段也只允许很小梯度通过。

若目标范围是 a 到 b，且 a<b，可以缩放：

$$\hat y=a+(b-a)\sigma(z)$$

σ(z) 把位置限制在 0 到 1 之间，乘 b-a 拉伸宽度，再加 a 平移起点。比如评分范围 0～100：ŷ=100σ(z)。

z σ(z) 100σ(z) d[100σ(z)]/dz
-2 0.1192 11.92 10.50
0 0.5000 50.00 25.00
3 0.9526 95.26 4.52

重要边界：对任何有限 z，缩放 Sigmoid 数学上只到开区间 (a,b)，不能精确达到端点。浮点计算可能因舍入显示为端点，但这不是函数的数学范围。若真实标签经常等于 0 或 100，必须检查端点误差、饱和与建模含义，不能只套公式。

5. 用同一组 z 比较四种映射

统一取 z=-2,0,3：

映射 z=-2 z=0 z=3 输出范围 主要代价
恒等 z -2 0 3 任意实数 不保证业务范围
Softplus 0.1269 0.6931 3.0486 正数 很负时梯度小
Sigmoid 0.1192 0.5000 0.9526 (0,1) 两端饱和
100×Sigmoid 11.92 50.00 95.26 (0,100) 两端饱和，不能数学上达到端点

6. 映射、目标、损失和数据分布一起选

输出映射只规定“能输出什么”，损失规定“错了怎样罚”，数据分布说明“什么误差常见”。三者必须共同考虑。

目标结构 常见起点 还要检查什么
任意实数 恒等映射 + MSE/MAE/Huber 噪声、异常值、业务误差代价
严格正值 Softplus 或对目标做合适变换 接近 0 时的梯度、长尾、单位尺度；正值不自动等于 Poisson
有限开区间 缩放 Sigmoid 真实端点值、饱和、校准、边界堆积
已知硬边界但模型仍需外推 恒等训练，预测后按业务规则处理并整体验证 截断是否掩盖模型失败，边界处误差怎样评价

例如用 MSE 配 100σ(z)：损失对 z 的梯度是

$$\frac{\partial L}{\partial z}=2(\hat y-y)\times100\sigma(z)(1-\sigma(z))$$

当 z 已在饱和区，第二项很小，即使预测与标签仍有差距，参数收到的信号也可能很弱。限制范围不是免费的。

7. Clip 与 Clamp：放在哪里会改变训练

把数值限制在 [0,1] 可以写成 clip(z,0,1) 或框架里的 clamp。例如 [-1,0.25,2] 变成 [0,0.25,1]。关键不在名字，而在它是否位于训练计算图中。

预测后 clip：模型训练仍用原始输出计算损失，只在交付结果时截断。它不改变训练梯度，但最终系统指标必须连同后处理一起评估。

训练图内 clamp：先令 ŷ=clamp(z,0,1)，再算损失。链式法则变成：

$$\frac{\partial L}{\partial z}=\frac{\partial L}{\partial\hat y}\frac{\partial\,\operatorname{clamp}(z,0,1)}{\partial z}$$

在区间内部，后一项为 1；明确小于 0 或大于 1 时为 0。端点恰好等于 0 或 1 的导数是实现约定，要查框架版本，不在这里笼统断言。

数值例：y=0.8、z=2。若训练内先 clamp，ŷ=1，平方误差为 0.04，但 z>1 的 clamp 导数为 0，所以这条支路 ∂L/∂z=0，无法把 2 拉回区间。不 clamp 时损失 (2-0.8)²=1.44，梯度 2(2-0.8)=2.4，仍有纠错信号。

因此 clip 不是所有输出约束的万能解。先确认边界来自物理规律、业务交付还是训练集偶然范围，再比较恒等、平滑映射、目标变换与后处理。

8. 同一个 Sigmoid，两种任务含义

在 03a 二分类中，σ(z) 被解释为类别 1 的概率，通常配合二元交叉熵，并关心概率校准与分类决策。在有界回归中，a+(b-a)σ(z) 表示一个连续数值，例如 0～100 的评分，可能配 MSE、MAE 或其他符合任务的损失。

数学函数相同，目标变量和损失定义不同：

  • 分类标签表达类别事件，0/1 不是距离刻度；
  • 有界回归标签表达连续大小，20 与 21 的差通常有数值意义；
  • 看到 Sigmoid 不能单独判断任务类型，要看标签语义、输出解释和训练损失。

9. 检查点

  1. 模型给出 z=-5 分钟时，为什么不能立刻说计算错误？
  2. 手算 Softplus(-2)、Softplus(0)、Softplus(3)，并解释为什么结果都为正。
  3. 为什么缩放 Sigmoid 对有限 z 不能精确达到 a 和 b？真实标签包含端点时要检查什么？
  4. 对 y=0.8,z=2，分别解释预测后 clip 与训练内 clamp 对梯度的影响。
  5. 分类和有界回归都能用 Sigmoid，为什么含义仍不同？
展开要点
  • z 只是原始实数输出；负数可能表示模型尚未学好，也可能说明任务需要输出映射。
  • Softplus 依次约为 0.1269、0.6931、3.0486；e^z>0 使 1+e^z>1，对数大于 0。
  • Sigmoid 只在极限中趋近 0 和 1；端点标签会带来不可达与饱和问题，需要比较误差、梯度和数据语义。
  • 预测后 clip 不改训练图；训练内 clamp 在明确越界处导数为 0，这条支路会失去纠错信号。
  • 分类输出是事件概率，有界回归输出是连续数值；标签与损失决定含义。
