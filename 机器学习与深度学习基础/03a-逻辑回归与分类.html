03a · 逻辑回归与分类

⏱ 9 分钟 ｜ 🧭 主线 ｜ ✋ 手算 ｜ 📐 有公式

🎯 一句话

逻辑回归 = 03 的加权求和 + 一个 Sigmoid：先算出一个分数，再把分数压成 0～1 之间的概率。名字里有“回归”，干的却是分类。

前置：02a（训练四步）和 03（多特征加权求和）。

🚦 一、问题变了：不问几分钟，问会不会超时

平台承诺“30 分钟送达”。下单时，它更想知道的是：这一单会不会超时？答案只有两种，“超时”记 1，“准时”记 0。这类问题叫分类；03 那种预测一个数的，叫回归。

为什么不直接用 03 的模型预测分钟数，再看是不是超过 30？

  • 很多时候，历史数据里只记了“超没超时”，没有记精确分钟数。
  • 我们想要的不只是“会 / 不会”，而是“有多大可能”。超时概率 90% 和 55%，应对方式不一样。

🧮 二、先算分数，再压成概率

第一步和 03 一样，加权求和，只是结果不叫“分钟”，叫分数 z。假设训练好的规则是：

$$z = 0.8 \times \text{距离} + 0.5 \times \text{排队单数} - 4$$

z 可以是任何数：正数越大越像会超时，负数越小越像准时。但概率必须在 0～1 之间，所以第二步用 Sigmoid 函数把 z 压进 0～1：

$$\hat p = \sigma(z) = \frac{1}{1+e^{-z}}$$

订单距离排队单数分数 z超时概率 p̂ = σ(z)
P2 km01.6 + 0 − 4 = −2.4约 0.08
Q4 km63.2 + 3 − 4 = 2.2约 0.90
R3 km22.4 + 1 − 4 = −0.6约 0.35

不用自己算 e 的几次方，看上图找到 z，往上对到曲线，就能读出大概的概率。

🎚️ 三、概率还不是答案：阈值

模型给的是概率。要变成“提醒用户 / 不提醒”，还得定一条线，叫阈值：概率超过它，就判为超时。

订单超时概率阈值 0.5阈值 0.3
P0.08准时准时
Q0.90超时超时
R0.35准时超时
  • 0.5 只是常见的起点，不是规定。
  • 如果漏报超时的代价很大（用户等得发火），就把阈值调低，宁可多提醒几单。阈值怎么定，05 讲指标时会展开。

📏 四、怎么算“错了多少”：交叉熵

训练还是 02a 那四步。只是“算损失”这一步换了公式，叫交叉熵：

  • 这单真的超时了（y = 1）：损失 = −log p̂。
  • 这单其实准时（y = 0）：损失 = −log(1 − p̂)。

算两次：Q 单真的超时了。模型说 0.9，损失 = −log 0.9 ≈ 0.11，罚得很轻；如果模型说 0.01，损失 = −log 0.01 ≈ 4.6，罚得很重。越自信地错，罚得越重。

$$\mathcal{L} = -\frac{1}{n}\sum \left[ y\log\hat{p} + (1-y)\log(1-\hat{p}) \right]$$

上式只是把两种情况合成一行：y = 1 时后半项是 0，y = 0 时前半项是 0。

梯度特别简单：交叉熵对分数 z 的梯度就是 p̂ − y。

  • Q 单超时（y = 1）、模型说 0.9：梯度 = −0.1，把 z 往上推一点点。
  • P 单其实也超时了、模型却只说 0.08：梯度 = −0.92，用力往上推。

为什么不用 MSE？上图右边：Sigmoid 配 MSE 时，自信地错（z 很小）反而几乎没有梯度，模型改不过来。

⭐ 经典考点：通常会让你「写出来」

  • 🔗 附录 C 第 10 题：把上图“梯度 = 预测 − 真实”写成 10 行纯 numpy 逻辑回归（breast_cancer 上 98.2%，sklearn 98.8%）
  • 🔗 附录 C 第 1 题：多分类版本，和这里是同一件事——softmax + 交叉熵的反向是 $p-\text{onehot}(y)$
  • 那边还回答了：逻辑回归为什么能零初始化而神经网络不行；本例为何不对偏置加 L2、何时另选

🧩 五、线性模型的能力边界

逻辑回归的“分数 = 加权求和”决定了：它只能用一条直线（特征多时是一个平面）把超时和准时分开。

这个局限直接催生了神经网络（07）：给线性模型套上非线性激活、再堆叠起来，就能画出弯曲的边界。

✅ 检查点

前 4 题是计算题，第 5 题用一句话回答。

  1. 按 z = 0.8 × 距离 + 0.5 × 排队单数 − 4，一单 1 km、排队 4 单，z 是多少？它的超时概率大于还是小于 0.5？（提示：z < 0 时 σ(z) < 0.5）
  2. 某单的超时概率是 0.35。阈值 0.5 和 0.3 下，分别判为什么？
  3. 一单真的超时（y = 1），模型说 0.5，交叉熵约是多少？另一单其实准时（y = 0），模型说 0.9，交叉熵约是多少？（log 0.5 ≈ −0.69，log 0.1 ≈ −2.30）
  4. 第 3 题第二单，对分数 z 的梯度 p̂ − y 是多少？下一步 z 会被往哪边推？
  5. 为什么二分类通常用交叉熵，而不是 MSE？
👀 答案
  1. z = 0.8 + 2 − 4 = −1.2，小于 0，所以概率小于 0.5（实际约 0.23）。
  2. 阈值 0.5：0.35 没超过，判准时；阈值 0.3：超过了，判超时。
  3. −log 0.5 ≈ 0.69；−log(1 − 0.9) = −log 0.1 ≈ 2.30。后者是自信地错，罚得更重。
  4. 0.9 − 0 = 0.9，是正的。按“新的 = 旧的 − 学习率 × 梯度”，z 会被往下推，概率随之变小。
  5. Sigmoid 配 MSE 时，自信但错误的预测几乎没有梯度，纠错很慢；交叉熵对 z 的梯度是 p̂ − y，错得越狠推得越猛。

⚡ 走神救援

  • 逻辑回归：先加权求和得到分数 z，再用 Sigmoid 压成 0～1 的概率。
  • 阈值：概率超过它才判为超时。0.5 只是起点，按漏报和误报的代价调整。
  • 交叉熵：真实是 1 罚 −log p̂，真实是 0 罚 −log(1 − p̂)，越自信地错罚得越重。它对 z 的梯度是 p̂ − y。
  • 能力边界：一条直线分不开 XOR，要靠非线性，这是走向神经网络（07）的理由。
