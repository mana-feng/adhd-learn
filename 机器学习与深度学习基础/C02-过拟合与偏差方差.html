C02 · 过拟合、欠拟合与偏差—方差：为什么记住训练题不够

⏱ 阅读约 22 分钟 · 实验另计

同一组三张训练样本，一条弯曲的函数全部猜对了；换成没见过的两个点，却可能远不如一条简单的水平线。

过拟合不是数学术语堆砌，而是模型从数据里记住了偶然噪声，换新样本便失灵。先完整算两个候选模型的训练和验证损失，再解释偏差、方差、学习曲线和如何改进。

学完会用训练/验证表现识别欠拟合与过拟合；亲手计算一组偏差与方差；不会把单次验证差距误认为对泛化能力的严格证明。

前置：03b · 损失函数 和 C01 · 评估指标。下一站：C04 · 交叉验证；马上在 C04 学习怎样组织交叉验证和独立测试。

一、为什么先给训练数据之外的题

为了只看模型记住噪声会发生什么，我们构造一个完全人为的回归实验。真实规律假设一直为 y=0；训练时的观测可能混入偶发测量误差。第一次采样恰好得到三组训练记录：

训练特征 x观测标签 y说明
00符合真实规律
12这一次观测碰巧有 +2 的噪声
20符合真实规律

我们还留出两个训练时没有出现的验证输入 x=0.5 和 x=1.5，两点真实目标都为 0。这里只是为了教学假定它们的干净目标值已知；现实中验证标签由独立观测得到，不能反过来帮助模型训练。

二、简单模型与复杂模型分别怎么预测

模型 A：始终预测训练标签的平均值。 三个训练标签是 [0,2,0]，所以 ŷ_A=(0+2+0)/3=2/3≈0.667。这里 ŷ 表示预测结果，输入 x 不影响这条水平线。

模型 B：用二次函数穿过三个训练点。 设 ŷ_B=ax²+bx+c，其中 a、b、c 是待拟合参数。把三个数据点代入：当 x=0,y=0 时得到 c=0；当 x=1,y=2 时 a+b=2；当 x=2,y=0 时 4a+2b=0。用第二式 b=2−a 代入第三式，得 4a+2(2−a)=0 → 2a=−4 → a=−2，进而 b=4。

ŷ_A=2/3

ŷ_B=−2x²+4x

两个模型都用同一份训练数据得到参数，但复杂的二次曲线把 x=1 那次偶然 +2 的噪声也完全拟合进去了。下面比较训练和验证损失。

三、MSE 谁更低？要分训练与验证两张表

回归损失统一用 MSE=(1/n)Σᵢ(ŷᵢ−yᵢ)²；n 是当前用于计算指标的样本数，i 枚举样本，yᵢ 是观测真值，ŷᵢ 是预测。

候选模型训练预测（x=0,1,2）训练 MSE（逐项代入）
A：常数2/3，2/3，2/3[(2/3−0)²+(2/3−2)²+(2/3−0)²]/3=8/9≈0.889
B：二次曲线0，2，0[(0−0)²+(2−2)²+(0−0)²]/3=0

只看训练集，B 完美。再看两个训练外验证点：

候选模型x=0.5 时预测x=1.5 时预测验证 MSE
A：常数2/32/3[(2/3−0)²+(2/3−0)²]/2=4/9≈0.444
B：二次曲线−2×0.5²+4×0.5=1.5−2×1.5²+4×1.5=1.5[(1.5−0)²+(1.5−0)²]/2=2.25

B 的训练误差从 0.889 降到 0，但验证误差反而从 0.444 涨到 2.25。在这次人为样本中，较复杂模型学进了训练噪声，这是典型过拟合现象；不能凭一次玩具实验推断“所有二次模型都比常数模型差”。

四、交互：切换模型、移动验证位置

切换模型，比较同一个新输入 x 的预测与两个固定验证点的整体 MSE。曲线画的是两条固定的候选模型，不是滑动 x 时重新训练。

当前新点预测 ŷ0.667
训练 MSE0.889
验证 MSE（固定两点）0.444

模型 A 对 x=0.5 的预测为 0.667。训练损失 0.889，验证损失 0.444。

建议操作：先选 B，看训练 MSE 直接归零；再看它对 0.5 的预测是 1.5，而真实目标是 0。返回 A，看看简单模型虽然训练没背完数据，验证反而更好。

五、偏差与方差到底分别是什么

前面只用了一次训练集，无法严格计算统计学上的偏差或方差。它们讨论的是：如果我们从相同的数据生成机制中反复抽训练集、反复拟合模型，同一个输入的预测会怎样变化。

假设真实函数仍为 f(1)=0，三次训练分别在 x=0、1、2 的不同位置出现一次幅度 +2 的噪声。每次训练用同样的模型族：

训练重复三个标签 [y₀,y₁,y₂]常数模型在 x=1 的预测插值二次模型在 x=1 的预测
第一次[0,2,0]2/32
第二次[2,0,0]2/30
第三次[0,0,2]2/30

这里用三次等权重复作为教学中的经验分布。二次模型在 x=1 的预测是 [2,0,0]，平均 (2+0+0)/3=2/3。相对真实函数 f(1)=0，平均预测偏差为 2/3−0=2/3，偏差平方为 4/9≈0.444。

方差是预测围绕其平均值的平均平方差：Var(ŷ)=[(2−2/3)²+(0−2/3)²+(0−2/3)²]/3=8/9≈0.889。反观常数模型三次都预测 2/3，平均一样，偏差平方也为 4/9，但方差 [(2/3−2/3)²×3]/3=0。

E[(ŷ−f(x))²] = (E[ŷ]−f(x))² + E[(ŷ−E[ŷ])²]

预测的平均平方误差 = 偏差² + 方差（此处比较已知无噪声的真实函数 f）

如果评估的是带随机观测噪声的标签 y=f(x)+ε，且 E[ε]=0、ε 与训练数据和预测误差独立，则还要加上噪声方差 Var(ε)；本例为了手算，验证目标被设为无噪声值。

偏差与方差的数学分解是在固定输入、平方误差、明确训练数据随机性的条件下成立；不意味着现实中的所有模型误差曲线都必须是简单 U 形。尤其现代神经网络还有过参数化和双降等现象。

六、学习曲线告诉我们什么，不能告诉我们什么

学习曲线会在不同训练样本数量下，分别计算训练表现与验证表现。如果二者都差，可能是欠拟合、特征不足或优化没到位；若训练很强而验证差，先排查过拟合，也要检查时间/群体分布变化和标签质量。

若随着新增训练数据，验证误差持续下降而训练—验证差距缩小，增加代表性数据可能有益；如果验证成绩进入平台，需进一步实验模型容量、特征、正则化或数据来源。学习曲线只提供排查线索，不保证再加数据一定有效。

在这个过程中不能反复打开最终测试集比较哪种方案更好。模型复杂度、正则化强度和是否追加数据，应在可靠的验证协议中决策；具体留到 C04。

七、如何应对欠拟合和过拟合

现象可优先调查的方向一定有效吗
训练与验证都表现差数据标签、特征信息量、模型容量、优化是否收敛不一定；先确认损失、标签和实验无 bug
训练好、验证差噪声拟合、数据泄漏、分布变化；尝试正则化、早停、增加代表性数据、减小容量不一定；需要在验证集逐项检验
训练好、验证也好检查指标是否对应目标，评估集是否独立且足够代表未来仍可能遇到部署分布漂移

不要直接把训练好、验证差等同于“高方差”诊断结论。那只是常见线索；真正的偏差与方差涉及跨多次训练集的期望，现实还可能存在泄漏、时间漂移或数据拆分不合理。下一节学会怎样建立可靠验证。

八、运行 Python 标准库验证算例

train_x, train_y = [0, 1, 2], [0, 2, 0]
valid_x, valid_y = [0.5, 1.5], [0, 0]

def simple(x): return 2 / 3
def curved(x): return -2 * x * x + 4 * x
def mse(xs, ys, fn):
    return sum((fn(x) - y) ** 2 for x, y in zip(xs, ys)) / len(ys)

for fn in (simple, curved):
    print(fn.__name__, round(mse(train_x, train_y, fn), 4),
          round(mse(valid_x, valid_y, fn), 4))
# simple 0.8889 0.4444
# curved 0.0 2.25

predictions = [2, 0, 0]
mean = sum(predictions) / len(predictions)
bias_squared = (mean - 0) ** 2
variance = sum((v - mean) ** 2 for v in predictions) / len(predictions)
print(round(bias_squared, 4), round(variance, 4))
# 0.4444 0.8889

九、检查点

  1. 为什么 B 在训练数据上 MSE=0，并不意味着它是更好的模型？
  2. 为何不能只看一组训练集，就说自己已经算出了统计意义上的偏差和方差？
  3. 重复训练的三组预测为 [2,0,0]，其平均、偏差平方和方差分别是多少？
展开答案

① 因为还要检查独立验证点；本例 B 记住了一次噪声，验证 MSE=2.25，较 A 更差。② 偏差和方差讨论跨训练抽样的预测分布，单次观测只提供训练与验证表现的线索。③ 平均 2/3、偏差平方 4/9、方差 8/9。
