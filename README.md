## 内容概览

### 通用方法论 (01-04)

数据策略、特征工程、对抗验证、验证集构造、训练正则化、模型融合、超参数调优等跨领域通用技术。

### NLP 竞赛 (05-08)

预训练模型选型与微调、文本分类、命名实体识别（GlobalPointer/CRF）、文本数据增强与输入处理。

### CV 竞赛 (09-12)

图像分类/检测/分割任务与模型选型、数据增强策略、损失函数设计、检测后处理与框融合（WBF/NMS）。

### 时间序列竞赛 (13-17)

结构化数据分析、传统建模与特征工程、量化交易多因子模型、深度学习因子挖掘、AutoML 调参。

### 推荐系统竞赛 (18-19)

召回层算法（协同过滤/双塔/图召回）、排序模型与多目标优化。

### 参考指南 (20-25)

技术选型时机、任务决策路径、竞赛元策略、数据泄露利用、金牌 Trick 汇总、实战 Pipeline 模板。
