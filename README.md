## 它和别的教程有什么不一样

大多数教程假设你能连续专注两小时，并且中断之后能自己接上。这套不这么假设。
每一章都带五个固定零件，**它们不是排版装饰，每一个都在解决一个具体的中断问题**：

| 零件 | 解决的问题 |
|---|---|
| ⏱ **时间徽章** | 「现在这段空档够不够读完」——所以它必须准。全站按 **170 字/分钟**统一量过，**宁可多报不少报**：标 30 分钟实际 80 分钟，人会中途弃坑，而且从此不再信这个数字 |
| 🎯 **一句话** | 全章压成一句。**只看这一句就走，是被允许的** |
| 🛑 **可以停在这里** | 明确的退出点。超过 55 分钟的章还会在中间插一个断点——**「停在这里」比「读不完的愧疚感」重要** |
| ⚡ **走神救援** | ⭐ 最特别的一个。全章要点会拆成可扫读的短要点；需要上下文时再展开原文。**隔几天回来只读这一块就能接上**，不用重读整章 |
| ✅ **检查点** | 6–10 题 + 折叠答案，只问正文真讲过的东西 |

另外：⭐ 是重点，⚠️ 是坑，💀 是**真出过事**的例子（写清发生了什么、为什么没被发现、代价多少）。

### 术语速查

正文中带点状下划线的常见术语可以点击。弹窗会用白话说明它是什么、有什么用，并给出最小代码或公式；首版覆盖 41 个 AI、工程、数据、SQL 与安全高频概念。每页最多标注 14 个术语，不会把正文变成满屏链接。

### 流程与清单的可视化

正文里的非代码内容不使用代码框或字符画。流程、编号步骤、对照、算账和要点会显示为信息图块；结构、分支、比例和架构会用节点图或 SVG。**只有可复制执行的代码、SQL 与终端命令**使用代码框。

内联流程图中的小标签会自动提高字号；每张图旁有精简的放大图标，可在弹窗内继续调节图示大小。

## 仓库结构与内容维护

| 位置 | 用途 |
|---|---|
| `index.html`、24 个板块目录 | 可离线阅读的教程与章节 |
